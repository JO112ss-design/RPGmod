# RPG Mod

Minecraft **26.3 / NeoForge** 向けのRPG系mod。「鍛冶ミニゲーム」と「職業システム（土台）」を実装しています。

## 鍛冶ミニゲーム

**鍛冶台**（鉄インゴット×3・鉄ブロック・石レンガ×2・かまど）を右クリックで開きます。

1. **作るものを選ぶ** — 武器6種（剣・短剣・メイス・ハンマー・魔法の杖・弓）と防具4種（ヘルメット・チェストプレート・レギンス・ブーツ）× 銅/鉄/金/ダイヤ。素材は通常クラフトと同じ数。**矢**（鉄1・棒1、バニラの矢）も作れて、品質で本数が変わる：普通4／良8／レア16／伝説32
2. **加熱** — 左右に動くバーを止めて初期温度を決める。右ほど高温（威力が高く、バーが遅い）
3. **部位を選ぶ** — 切先・前部・中央・後部・根元をクリック（または 1〜5 キー）
4. **鍛打** — バーを止める（クリック / スペース）。止めた位置で威力が変わる：中央の赤＝強 100% / 黄＝中 75% / 外側の緑＝弱 40% / 枠外＝ミス 0%
   - 叩いた部位に100%、左右の隣に25%
   - 1回叩くごとに温度 −5。温度20以下で強制終了
5. **冷却** — 温度 −15。威力を落として微調整したいときに
6. **仕上げる** — 誤差（不足は×1.0、超過は×1.5で減点）から品質が決まる

| 品質 | オプション数 | 色 |
|---|---|---|
| 普通 | 1 | 灰 |
| 上質 | 2 | 青 |
| 希少 | 3 | 紫 |
| 伝説 | 4 | 金 |

素材が良いほど難しくなります（バーが速く、強・中・弱の幅が狭く、品質判定が厳しい）。難易度：銅×0.85 / 鉄×1.0 / 金×1.1 / ダイヤ×1.2（設定で変更可）。

オプション（重複なし・数値ランダム）
- 武器: 攻撃力、攻撃速度、会心率、会心ダメージ、ボス特効、最大HP（%）、防御力、移動速度、獲得経験値、ノックバック耐性、最大MP（+10〜25）、MP回復（+8〜20%）、魔法攻撃力%・詠唱短縮（杖のみ）
- 防具: 防御力、防具強度、最大HP、移動速度、ノックバック耐性、耐久値（盾のみ）、獲得経験値、被ダメージ軽減、ボス耐性、魔法攻撃力%、詠唱短縮、最大MP（+5〜12）、MP回復（+4〜10%）（複数部位で重ねがけ可）

- 武器の効果はメインハンドに持っている間、防具の効果は装備している間だけ有効
- **会心**：バニラの落下会心とは別枠。会心率＝職業＋鍛冶武器（合計で1回抽選）、倍率＝1.5＋会心ダメージ。近接・矢・スキル・魔法すべてに適用し、落下会心とは掛け算で重複
- 通常クラフトの武器はオプションなし
- ダイヤ → ネザライトへのアップグレードで品質・オプションを引き継ぐ（武器・防具とも）
- 品質・オプション・製作者はアイテムに保存され、受け渡しやサーバー再起動でも消えない


## 宝石とソケット

装備に「宝石」をはめて追加効果を付けられます。宝石は1つにつき効果1つ。一度はめると取り外せません。

- **ソケット数**：武器・防具・盾すべてに付けられる。銅・鉄・金（とバニラの盾）は1個、ダイヤは2個、ネザライトは3個。ネザライトにアップグレードしても付いている宝石は残る
- **ソケット台**：作業台で「紫水晶の欠片×4＋ダイヤ×1＋鉄インゴット×2」（ADA／AIA／ I ）。左に装備、右に宝石を置いて「装着」。MC経験値を5レベル消費。同じレジェンダリー効果は1つの装備に1つまで
- **効果が働くとき**：その装備を持っている（武器）・着ている（防具）・オフハンドに構えている（盾）間
- **入手**：プレイヤーが倒したモンスターから 0.6%（幸運・ドロップ増加の影響なし）。Lv100を超える敵からは少しずつ上がり、Lv200で 1.5%。ボス（エンダードラゴン・ウィザー・キングスライムなど）は必ず1個落とす
- **レアリティの出やすさ**：通常の敵 コモン80%／レア17%／レジェンダリー3%、ボス コモン50%／レア35%／レジェンダリー15%

| レアリティ | 効果 |
|---|---|
| コモン（緑） | 鍛冶のランダム効果と同じ種類で、数値は鍛冶の約3分の1を**整数に丸めたもの（最低1）**。攻撃力・魔法攻撃力は％ではなく**固定値+1〜3**（Lv100の攻撃力の約1〜3%）、最大HPは%（+1〜2%）。会心率+1〜2%、最大MP+3〜8 など（耐久値以外） |
| レア（青） | 半分はコモンの1.5〜2倍の数値。残り半分は特殊効果：吸血（与ダメの3%回復、5秒に1回／重ねて最大9%）／茨（近接で受けたダメの7%を返す／最大21%）／鈍化（5%で鈍足／最大15%）／毒牙（3%で毒／最大9%）／背水（HP半分以下で与ダメ+5%／最大15%）／追い風（敵を倒すと2秒スピードアップ／最大6秒）／軽業（落下ダメ-17%／最大51%）。同じレア効果は重ねると足し算（上限まで） |
| レジェンダリー（金） | 炎上（攻撃した敵を4秒燃やす）／無限の矢（矢を消費しない）／魔力吸収（攻撃が当たると最大MPの3%回復、5秒に1回）／雷撃（15%で雷、そのヒットの半分の追加ダメージ）／不死鳥（致死ダメージをHP1で耐える、5分に1回）／再生（5秒ごとに最大HPの2%回復）／衝撃波（会心時、周囲3マスの敵にその50%）／氷結（20%で2秒動けなくする）。同じ効果は1つの装備に1つまで、重ねても1つ分 |

- コモン・レアの数値は、鍛冶の効果や他の宝石と足し算で重なる。数値を下げる前に拾った宝石も、自動で新しい基準（3分の1）で効く。会心率などの武器用の効果も、防具にはめれば有効
- 攻撃時の効果は通常攻撃・矢・スキルのどれでも発動する（宝石自身のダメージでは連鎖しない）。ボスには鈍化・氷結が効かない（毒も無効）

## 職業システム（土台）

12職業から、ワールドに初めて入ったときに1つ選びます。あとから「転職の書」で別の職業に変えられます（下の「転職」）。

| 職業 | スキルが使える武器 |
|---|---|
| ファイター | 剣・ハンマー |
| レンジャー | 弓 |
| パラディン | メイス・剣 |
| ウィザード | 魔法の杖 |
| ヒーラー | 魔法の杖・メイス |
| アサシン | 短剣 |
| エンチャンター | 魔法の杖・短剣 |
| ギャンブラー | 短剣・弓 |
| パイレーツ | 銃剣 |
| ランサー | 槍 |
| モンク | ナックル |
| バード | リュート |

- **攻撃側の数値の大きさ**：攻撃力・魔法攻撃力は**バニラの3倍のスケール**（素手3、剣の攻撃力9、矢の攻撃力も3倍）。敵の体力も3倍なので、倒すまでの発数は変わらない。そのぶん数字が細かく調整できる（宝石の攻撃力+1が約1%など）。力のポーション（+9/段）・弱体化（−12/段）も3倍分。敵を倒したときの職業経験値は、体力が3倍になった分を割り戻しているので今までと同じ
- **レベルによる攻撃力の伸び**：攻撃力（魔法職は魔法攻撃力）は**レベルごとに0.6（整数に切り捨てて、ほぼ毎レベル+1）**（Lv100で+59、Lv199で+118。魔法職の物理と、エンチャンターの短剣は0.3）。上級職の分はなし。武器の素材の倍率がこの伸びにも掛かるので、レベルが上がるほど良い武器の差が大きくなる
- **初期装備**：職業を選ぶと、その職業が使える武器をすべて銅で受け取る（メインの武器が先頭：ウィザード・ヒーラーは杖、レンジャーは弓、他は近接武器）。弓を使う職（レンジャー・ギャンブラー）は矢64本も。ほかに鍛冶台とソケット台を1つずつ（台は最初の職業のときだけ。転職で初めてなった職業は武器と矢だけもらえる）
- **成長**：モブを倒すとEXP（最大HPに比例、ボスは3倍・キングスライムは等倍、近くの仲間にも同量）。レベルごとにスキルポイント+1（最大Lv100）。必要EXP＝(15＋2.5×Lv＋Lv²÷8)×序盤補正×2.5。序盤補正はLv1で×3、Lv40で×1に向けてなだらかに下がる（同じくらいの敵で1レベルあたり約6体→Lv20以降は約15体）。Lv100まではこの半分（Lv40までの合計は約9000、Lv100までは約7万）、上級職（Lv101以降）は0.9倍（Lv100→199は、Lv1→100のだいたい4倍の時間）
- **スキルパネル**：職業ごとのハニカム盤面（半径7・169マス）。中央から隣り合うマスを解放。ホイールで拡大縮小、ドラッグで移動
  - ステータスのマス：内側（1〜3周）1pt、中間（4〜5周）は効果1.5倍で2pt、外側（6〜7周）は2倍で3pt
  - スキルは2〜6周目に角度をずらして散らばり（2〜4pt）、必殺技は外周の反対側に2つ（5pt）
  - 攻撃力・魔法攻撃力・防御力はレベルアップとパネルの両方で強く伸びます（敵のレベルに合わせて2倍に強化）
  - **最大体力**はキャラクターレベルで毎レベル同じだけ伸び、Lv199で 近接など500／パラディン（ガーディアン）600／ウィザード・ヒーラー・エンチャンター300（Lv100では約260／310／160。パネルの体力マス +2〜4 は別に加算）。レベルで防御力は伸びない（防御は防具で決まる）
  - 旧データはレベルが「×2−1」に換算され、ポイントは全額返却
- **転職**：「転職の書」を使うと職業選択画面が開き、職業を選んだときに1冊消費（閉じれば消費しない）
  - **レベルはキャラクター共通**：転職してもレベル・EXP・スキルの書のポイントはそのまま。敵のレベルもこのレベルで決まる
  - **熟練度（職業ごと）**：その職業でいる間に得たEXPが貯まる。100%＝Lv1→100に必要なEXPの合計（約7万）。Lv100以上のときは2倍で貯まる。最初の職業はLv100になった瞬間にちょうど100%
  - **スキルパネル**：振り方は職業ごとに保存され、戻ると前の状態のまま。基本職のパネルで、ステータスのマスはいつでも取れるが、スキル・呪文は4周目が熟練度25%、5周目が50%、6〜7周目が75%、必殺技は100%で解放（マスに赤字で必要な%）
  - **上級職**：その基本職の熟練度100%で選べる（書の画面の「上位職」タブ）。解放前は名前・色・スキルが「？？？」で隠れている。熟練度100%なら必ずLv100以上。上級職を選ぶまでは、Lv100を超えた分のポイントは「上位職のポイント」として貯まり、上級職になると全部使える
  - **極めたご褒美**：職業の熟練度が初めて100%になると転職の書を1冊もらえる（全員に告知）。熟練度100%の職業1つにつき最大HP+2%
  - **入手**：モンスターから0.5%（幸運では上がらない）、ブラッドムーンのボスとエンダードラゴンからは必ず1冊
  - 転職前からのデータは、今の職業の熟練度＝そこまでに得たEXP（Lv100以上なら100%で、上級職のまま）。覚えていたスキルはそのまま
  - 管理者コマンド：`/rpgjob mastery <プレイヤー> <職業> <%>`、`/rpgjob advance <プレイヤー>`（書なしで上級職に）
- **MP**：時間で自然回復。30秒間攻撃も被弾もしないと回復が3倍（HUDに「MP回復 ×3」）。設定 `restRegenDelay`・`restRegenMultiplier`
- **物理職とバード系のMP**：ステータスにMPを持たない職（ファイター・レンジャー・パラディン・アサシン・ギャンブラー・パイレーツ・ランサー・モンクとその上級職、ゴッドハンド・センチネル・シャドウハンター・トレジャーハンター）とバード・マエストロ・スペルシンガーは**最大MP100で固定**（レベルで増えない。装備のMP効果は乗る）。物理職は**通常攻撃を敵に当てるとMPが回復**：前に回復してからの時間×毎秒2（最大1.5秒分＝3）。回復は0.5秒に1回までで、8割以上溜めた攻撃（弓は引き切った矢、パイレーツの銃は全弾）だけが対象なので、連打では回復しない（殴り続ければどの武器でも毎秒約2）。スキル・なぎ払いの巻き込みでは回復しない。物理職の自然回復は戦闘中は3分の1（戦闘外の3倍回復はそのまま）。バード系に攻撃での回復はない
- **必殺技の範囲**：敵を巻き込む範囲・陣の必殺技は範囲が2倍（大地割り・アローレイン・審判・メテオ・時間停止・聖域・大呪詛・ジャックポット・一斉砲撃・竜牙・千本槍・百裂拳・終幕・闘神・魔法剣・極・属性解放・天地の気・百花繚乱・不落の砦・大ルーン陣・艦隊砲撃・天地無双・竜王降臨（燃える地面も）・交響曲・財宝の雨・黄金の大砲）。味方への強化の届く範囲も2倍（大付与・守護の光・不落の城塞・大いなる奇跡・海賊旗・大合奏・大協奏の余韻・神の盾の対象選び）
- **広範囲の持続ダメージの必殺技は効果時間1.5倍**：アローレイン3秒・聖域12秒・千本槍4.5秒（1回に3本ずつ降る）・財宝の雨4.5秒・艦隊砲撃7.5秒・竜王降臨の燃える地面6秒・大ルーン陣22.5秒・交響曲18秒・一斉砲撃12列
- **必殺技の見直し**（似ていたものを作り直し）：狂戦士→闘神（次の通常攻撃5回が衝撃斬）、影舞（影2体が通常攻撃をまねる）、神の盾（味方1人を6秒無敵＋全回復）、守護の光（受けたダメージの半分を3秒で回復）、時間遅延→時間停止（3秒、止まっている間のダメージは解除時に+20%）、ほか不落の砦・百花繚乱・極大魔導砲・竜牙・交響曲・大協奏・魔奏・終曲
- **物理職のスキルのMPとクールタイム**：小技・移動 8MP／2.5〜4秒、主力攻撃 15MP／4〜5秒、妨害 15MP／6〜10秒（拘束は効果時間の2倍以上）、大技・範囲 22MP／6〜7.5秒、強化・防御 20MP／15〜25秒（効果時間は以前の2倍）、必殺技 40MP／120秒（無敵・守り系は150秒）が目安。クールタイムが短い分、MPをどう回復するか（殴る・自然回復・ポーション）が選択になる
- **スキル**：Z・X でスキル1・2、C で必殺技（キー設定で変更可）。パネルで覚えたスキルを付け替え可能。職業の武器を持っているときだけ発動、クールタイムとMPあり。必殺技のクールタイムは長め（通常の値の2倍）、蘇生の祈り・大いなる奇跡は5倍。蘇生の祈りは経験値レベル10を消費し、ダウンした味方がいるときだけ使える
- **ウィザード**：杖ごとに呪文4枠。V長押しで円形メニューから選び、右クリックで詠唱
- **画面**：K で職業メニュー（ステータス／スキルパネル／スキル／呪文）。画面右下にレベル・EXP・MP・スキルのクールタイム
- スキルの数値は `JobDefs`、当たり判定と動きは `SkillExecutor`、見た目は `client/fx/`

### スキルのダメージ計算

```
スキルダメージ = 攻撃力 × スキル倍率
```

- **攻撃力**（剣・短剣・メイス・ハンマー・弓の職業）=（素手3 ＋ 武器の攻撃力 ＋ 自身の攻撃力 ＋ 力のポーション）× 武器の素材の倍率 ×（1 ＋ 鍛冶の攻撃力%）。弓は「矢を引き絞った攻撃力 18 ＋ 素材ボーナス」を武器の攻撃力として数えます
- **武器の素材**：武器の種類の攻撃力（剣9・短剣3・メイス12・ハンマー18・杖4.5）に**小さな固定値**を足し、さらに持っている間は**攻撃力全体に倍率**（自分の攻撃力ごと）。銅 +3 ×1.0／鉄 +9 ×1.1／金 +12 ×1.2／ダイヤ +15 ×1.33／ネザライト +18 ×1.45。剣のファイターだと Lv1銅 21／Lv50鉄 62／Lv100ダイヤ 122／Lv199ネザライト 223（Lv199の銅は139）。固定値があるので、序盤に鉄の武器へ替えても手応えがある（Lv1で 21→30）。弓は矢（満タン18）に固定値を足して倍率、杖は魔法攻撃力「9＋固定値」で倍率も同じ
- **重量武器補正**：メイスとハンマーは通常攻撃（スキル以外）のダメージ全体に倍率がかかる（メイス×1.25、ハンマー×1.6。`rpgmod-jobs.toml` の `maceAttackMultiplier` / `hammerAttackMultiplier`）。スキルのダメージには影響しない。Lv100・ダイヤの通常攻撃の秒間ダメージは剣を100としてメイス約94%・ハンマー約80%
- **魔法攻撃力**（ウィザード・ヒーラー・エンチャンターのスキルと呪文）=（3 ＋ 杖の魔法攻撃力 ＋ 自身の魔法攻撃力 ＋ 宝石の魔法攻撃力）× 杖の素材の倍率 ×（1 ＋ 鍛冶の魔法攻撃力%）。杖：銅12／鉄18／金21／ダイヤ24／ネザライト27、倍率は武器と同じ
- **自身の攻撃力・魔法攻撃力**は職業の初期値＋レベルアップ（0.6/レベル）＋スキルパネル（1マス +0.6〜1.2。武器の倍率も掛かる）で増えます
- **スキル倍率**：攻撃スキルは表の倍率の**0.75倍**で計算（回復・バフと、ウィザードの通常攻撃にあたるマジックボルト、ガーディアンの報復は対象外）。強撃は3.0→2.25で、同じレベルの敵の体力の4割ほど（スキル1発＋通常攻撃2〜3発で倒せる）。ヒール（回復）90% など。職業画面のスキル説明に「威力 攻撃力×300%（今 21.0）」と表示
- **個別の調整**：ロシアンルーレット 倍率10→6・CT2→3秒、審判 2.5→6.0、大地割り 5.0→8.0、サンダー 3.3→4.5、重力 2.4→3.6（いずれも0.75倍の前の値）
- そのあと会心・ボス特効・敵の防具（魔法も同じく防具で減る）が掛かります。スキル威力と防具貫通は廃止（貫通の付いた鍛冶装備・宝石は同じ数値の攻撃力%として働く）
- **弓の通常射撃**にも自身の攻撃力（レベル・パネル・力のポーション／付与・鬨の声など。弱体化はマイナス）が乗ります。引き絞り具合に比例し、満タンで「ステータス画面の攻撃力」と同じダメージになります（そのあと会心）
- **エンチャンターのバフ**（付与・加速20秒・炎の付与・大付与30秒）の効果時間は魔法攻撃力で増減：表記の時間 ×（魔法攻撃力 ÷ 10）、0.5〜3倍。スキル説明に今の効果時間を表示。設定 `enchanterBuffReferenceAttack` / `enchanterBuffMinMultiplier` / `enchanterBuffMaxMultiplier`
- スキル消費MP：ファイター・レンジャー・パラディン・アサシン・ギャンブラーは一度半分にしたあと、全職業×1.4（例：強撃10.5、メテオ112、ヒール21）
- ウィザード以外の職業の攻撃スキル倍率は2倍に調整済み（回復・MP回復・移動系は据え置き。聖なる波・カード投げ・ギャンブルの回復/MP/自爆分は倍率が上がっても以前と同じ量）
- ウィザードの攻撃呪文（マジックボルト以外）は倍率1.5倍、メテオは3倍（9.0）に調整済み。マジックボルトは威力そのままで、クールタイム0.3秒・消費MP5（通常攻撃のように撃ち続けられる）

### スキルの演出と範囲

全72スキルに専用の演出があります。自作の発光パーティクル（加算合成）で、魔法陣・斬撃の弧・衝撃波・氷片・羽・コインなどを描きます。サーバーは「何が起きたか」だけを送り、パーティクルはクライアントで時間差アニメーションするので、マルチでも通信は軽いです。ビデオ設定の「パーティクル」を減らすと演出の量も減ります。

| 種類 | 例 | 当たり方 |
|---|---|---|
| 扇形 | 強撃（半径4.5・左右65°）、盾打ち（4）、毒刃（4） | 前方の扇形に一度 |
| 周囲 | 旋風斬（4.5・2回ヒット）、フロストノヴァ（6） | 広がる波が届いた順にヒット |
| 衝撃波 | 大地割り（7） | 地面を走る衝撃波が通過した敵に |
| 狙い撃ち | マジックボルト（28・追尾）、裁きの一撃（8）、暗殺（12） | 照準に近い敵を自動で狙う |
| 着弾点 | メテオ（36先・半径11）、サンダー（28・連鎖3体）、アローレイン（32・半径10）、罠（14） | 見ている地面に予兆→時間差で着弾 |
| 設置 | 聖域（6・8秒）、罠（4秒） | その場に残り続ける |
| 移動 | ブリンク（10）、影歩き（敵の背後へ）、突進 | 壁や地面に埋まらない位置へ |

- 大技（メテオ・大地割り・審判など）は近くのプレイヤーの画面が揺れます
- 杖の詠唱中は足元に魔法陣が広がり、詠唱完了で光ります
- 会心とレベルアップにも専用の演出
- **スキルの付け替え**：スロット（スキル1・2・必殺技、杖の魔法）に新しく入れたスキルは**10秒間使えない**（もともと残っていたクールダウンの方が長ければそちら）。戦闘中に付け替えて次々使うのを防ぐため。スロット1と2の入れ替えだけなら掛からない（設定 `skillSwapCooldown`）
- **効果時間はレベルで伸びる**：効果時間のあるスキル・魔法は、レベルに応じて最大+50%（Lv100）まで長くなる。必殺技と、魔法攻撃力で伸びるエンチャンターのバフは対象外（設定 `skillDurationBonusAtMax`）
- 消費MPはすべて整数
- **幸運**（ギャンブラーが伸びる）：幸運1につき5%（最大50%）の確率で、ギャンブルを**もう1回振って良い方を取る**。対象はコイントス・ダイス・オールイン・ジャックポット（大当たり＞強化＞回復＞MP＞呪い＞自爆の順で良い方）、ルーレットの出目（大きい方）、ラッキーショットの当たり、ロシアンルーレットの発砲、カード投げのスペード。ステータス画面に「振り直し○%」と表示（設定 `luckRerollPerPoint`）
- **盾**：ガードで防げるのはダメージの一部だけ（残りは受ける）。バニラの盾20%、鍛冶の盾は銅40%／鉄50%／ダイヤ60%／ネザライト60%（パラディンはどの盾でも+20%）。
- **装備は壊れない**：鍛冶で作れる武器（剣・短剣・メイス・ハンマー・杖・弓）と防具（頭・胴・脚・足）は、銅〜ネザライトまで耐久が減らず壊れない（作業台で作ったもの・拾ったものも同じ）。革・チェーンの防具、つるはし・斧などの道具は今まで通り
- **盾の耐久**：盾は壊れない。ガードで耐久が0になると「壊れた」状態になり、30秒（ネザライトは15秒）ガードできない（斧で割られたときと同じクールダウン表示）。時間が経つと耐久満タンで復活する。インベントリやチェストに入れていても時間で戻る（次に手に取ったとき）。盾を構えている間はスキル・魔法を使えない
- **盾の作り方**：鍛冶台で「バニラの盾1＋インゴット（ダイヤ）3」から銅・鉄・ダイヤの盾を鍛える（防具と同じランダム効果。オフハンドで効く）。作業台でも同じ材料で効果なしの盾が作れる。ネザライトは鍛冶型（ネザライトアップグレード）でダイヤの盾から。見た目は素材の色の盾

- **パイレーツ（銃剣・中衛）**：銃剣を**右クリックで発射**（攻撃力×90%、射程32、0.5秒に1発）。**6発撃つと自動で装填**（2秒。しゃがみ＋右クリックで早めに装填）。**銃剣で敵を突く（通常攻撃）と1発込め直される**。照準の下に残弾。スキル：突撃射（踏み込んで突き＋至近射撃、1発装填）・早撃ち（残弾を全部連射、最低3発）・大砲設置（横に大砲を置き10秒間、近くの敵を自動砲撃。範囲ダメージ）・火薬樽（2秒後に爆発。撃ち抜くとその場で1.5倍の誘爆。地形は壊さない）・かぎ縄（敵を引き寄せる／大きい敵には自分が飛ぶ／敵がいなければ狙った場所へ）・ラム酒（HP15%回復＋攻撃速度）・必殺技：一斉砲撃（背後から頭上を越えて砲弾が飛び、狙った範囲を手前から奥へ1列3発ずつ絨毯爆撃）・海賊旗（旗の周りの味方の与ダメージ+20%、15秒。その間は大砲の連射2倍、弾切れなし）

- **モンク（ナックル・近接）**：**気（0〜5）**：ナックルの通常攻撃で+1、照準の下に表示。8秒戦わないと1秒に1ずつ減る。スキル：連撃（3連打、当たるたび気+1）・発勁（気を全部使い、1つにつき威力+80%）・受け流し（1.2秒、次の近接攻撃を無効にして反撃、気+2）・旋風脚（周りを蹴り飛ばし、当たった数だけ気、最大2）・瞑想（3秒動けない、毎秒最大HPの8%回復、最後に気が満タン）・縮地（狙った敵の背後へ瞬間移動して背中を打つ。背後からなので1.3倍、残像が残る、気+1）・必殺技：百裂拳（3秒間の連打＋最後に強打）・金剛（6秒、受けるダメージ−80%、吹き飛ばされない、攻撃が当たるたび気）
- **バード（リュート・支援）**：**曲はウィザードの呪文と同じくリュートにセット**（4枠、ホイールで選ぶ）し、スキル「**演奏**」で選んでいる曲を演奏する（どの曲も12秒。MPとクールダウンは曲ごと）。画面下に**音符のレーン**が出て、音符が右から流れてきて左の線に重なったときに**左クリック**：±2ティックで**パーフェクト**（+2）、±4で**グッド**（+1）、それ以外・見逃しは**ミス**（−3）。この点数（0〜20）で歌の強さ60%〜120%、届く範囲6〜10ブロック。16点以上で歌が終わると**アンコール**（6秒延長、1回）。演奏中は移動が遅くなり、剣などの通常攻撃はできない（左クリックは演奏用）。**リュートを右クリックで音波**（魔法攻撃力×80%、1発2MP、演奏中も撃てる）。曲：戦いの歌（与ダメージ+9〜18%）・癒しの歌（毎秒最大HPの1.2〜2.4%回復）・守りの歌（受けるダメージ−9〜18%）・風の歌（移動+12〜24%・攻撃速度+9〜18%）・不協和音（周りの敵に毎秒ダメージ＋防御ダウン）・子守唄（周りの敵の動きと攻撃が鈍る）・狂詩曲（会心率+9〜18%）・凱歌（スキルのクールダウンが早く回る）・葬送曲（周りの敵から毎秒HPを吸い、その3割で味方を回復）。スキル：演奏・衝撃音（前方に音の衝撃波、吹き飛ばし。演奏中も使える）・鼓舞（演奏の点数+6、味方の攻撃力を5秒アップ）・必殺技：大合奏（10秒、4つの歌を最大の強さで同時に）・終幕（演奏を終え、点数に応じた衝撃波）。エンチャンターとの違い：自分の周りにいる間ずっと効く・上手に弾くほど強い・同時に1曲

### 複合職

2つの基本職の熟練度を**両方100%**にすると、転職の書の上位職タブ（3段目）で選べる。上級職と同じく、解放されるまで名前は「？？？」。
- 基本職のステータスやスキルは**引き継がない**。複合職だけのステータスと成長（全レベル分）、**パネル1枚に全レベルのポイント**（熟練度による制限なし）、スキル枠3つ＋必殺技
- **魔法戦士**（ファイター×ウィザード・剣）：剣に火・氷・雷のどれか（属性切替で変更、照準の下に表示）。剣の通常攻撃にも自分の魔法攻撃力の半分が属性で乗る（火＝燃える、氷＝一瞬鈍る、雷＝近くの敵に飛ぶ）。**剣で右クリック長押しで属性魔法**：スニークしながら右クリックすると普通の右クリック（左手の盾・食べ物・ブロックなど）。溜めている間は杖の詠唱と同じく足が遅くなる。照準の下の3段ゲージで、今のMPで足りない段は赤く表示（そこまで溜めても足りる段で撃つ）。最低0.8秒溜める必要があり（それより早く離すと不発、MPは減らない）、0.8秒／1.8秒／2.8秒の3段階で強く（詠唱速度で短くなる）、MPも多く使う（火＝着弾で爆発する火球 10/24/45MP、氷＝狙った地点の広範囲（2段目以降はさらに大きく）・威力は控えめ・0.5秒だけ鈍足 12/28/50MP、雷＝狙った1体に落雷・単体最強、最大溜めで気絶 14/32/55MP。会心は出ない。MPはヒーラーと同じくらい伸びる。扉やチェストに向けたときは普通に開ける）。スキルの威力は**攻撃力＋魔法攻撃力**。魔法剣・斬（火＝回る炎の輪が当たった所で爆発、氷＝幅広くゆっくり進み全員を一瞬鈍らせる、雷＝一瞬で斬り3体へ飛び移る）・雷迅突（雷になって一瞬で直線移動、その間は無敵。少し遅れて通った道に雷が落ちる）・魔力譲渡（最大MPの20%を消費し、その2倍を周りの味方全員に）・魔力瞑想（座ってMP回復が大きく速まる、最大15秒。もう一度使う／動く／攻撃で解除）・魔法障壁・必殺技：魔法剣・極／属性解放
- **ゴッドハンド**（ヒーラー×モンク・ナックル）：気はモンクと同じ（ナックルで溜まる）。気功弾（気1つで威力+80%）・練気・治癒の掌（自分と周りを回復）・硬気功（気を使って被ダメージ減）・発勁・癒（与ダメージの3割回復）・流水歩（近くの敵3体の間をジグザグに縫って打つ。触れるたびにHP4%回復）・必殺技：天地の気（大回復＋衝撃波）／百花繚乱（8秒の花の陣。中から攻撃を当てるたびに陣の中の味方が回復、終わりに花が散ってダメージ）
- **センチネル**（パラディン×ランサー・槍＋オフハンドに盾）：槍の先の+25%もある。守突・盾突撃（盾で最大5体を押し込みながら突進。壁にぶつけると2.5秒気絶＋大ダメージ、壁がなければ最後に押し飛ばす）・不動の構え（被ダメージ−40%）・槍衾（その場に槍の陣）・反撃の槍（3秒間盾で構え、受けるダメージ60%減。防いだ分を4倍で溜め、構えの後6秒以内の次の近接攻撃に上乗せ）・挑発・必殺技：不落の砦（10秒間、周りの味方の被ダメージ−30%。防いだ分を溜めて終わりに槍の衝撃で放つ）／聖槍（前方一直線）。初期装備に盾も付く
- **スペルシンガー**（エンチャンター×バード・リュート）：演奏はバードと同じ（リュートに曲をセットして「演奏」、音符のレーン）。**曲の効果はバードより控えめだが、曲が終わった後も、終わったときの点数に応じて長く残る（余韻：1点につき5秒、最大100秒。MP回復と雷は毎秒続く）。切れたらかけ直す使い方**。曲：炎の旋律（味方の攻撃が燃えて威力アップ）・加速の調べ・魔力の和音（味方のMP回復）・封印の旋律（敵の守りを崩す）・雷鳴の調べ（毎秒敵1体に雷）・守護の旋律（味方に衝撃吸収＝HPバーの黄色、最大HPの15〜30%。削られた分は戻らず、割れると4秒間は付かない。演奏が終わったとき近くにいた味方は、残っている分が200秒続く）・吸魔の調べ（味方の攻撃が当たるたびにMPが少し回復）。スキル：演奏・魔音符（追いかける音符を3つ）・共鳴（味方の良い効果を5秒延長）・必殺技：大協奏（セットした全曲の余韻を最高点で100秒）／魔奏・終曲（点数の数だけ追尾する音符、当たった敵は3秒間攻撃できない）
- **シャドウハンター**（アサシン×レンジャー・弓＋短剣）：急所狙い（体力半分以下の敵に2倍）・隠密（姿を消し、次の一撃は必ず会心で+60%）・影縫いの矢・罠設置・影跳び・扇投げ・必殺技：闇夜の狩り（10秒、周りの敵すべてを獲物に＝自分からのダメージ+50%）／影の雨（狙った1体に影の矢を集中して縫い止める。命中ごとに近くの敵へ跳ねて半分のダメージ＋縫い止め）
- **トレジャーハンター**（ギャンブラー×パイレーツ・銃剣）：銃剣の銃も使える。ギャンブル砲（爆発・氷・毒・金貨・不発・大当たりのどれか）・金貨散弾・宝箱の罠（敵を引き寄せて噛みつく）・盗む（宝石ではなくエメラルドや金塊など、1体1回）・幸運の羅針盤（120秒、倒した敵が宝を落とす）・ダブルダウン（12秒、ダメージが毎回2倍か半分）・必殺技：財宝の雨（金貨の雨。一部は地面に残り、拾うとゴールドラッシュ＝与ダメージ+5%、最大5重）／黄金の大砲

- 管理者コマンド：`/rpgjob info|reset|set|level|exp <プレイヤー> ...`
- 敵を倒した経験値は、倒した人から**70ブロック以内**にいるプレイヤー全員がまるごと受け取る（同じディメンションのみ）
- 設定：`config/rpgmod-jobs.toml`（`maxJobLevel` 最大レベル、EXP倍率、共有範囲 `expShareRadius` など）

## 敵の強化

### 敵レベル

モンスターは出現したときにレベルが決まり、強くなります（一度決まったレベルはそのまま保存）。

- **標準**：オンラインのプレイヤーのうち一番高い職業レベル ＋0〜3（例：最高Lv31なら Lv31〜34）。エンダードラゴンはLv200固定
- 設定 `levelsFromPlayers = false` にすると、場所で決める方式になります：

| 場所 | レベル | 決まり方 |
|---|---|---|
| オーバーワールド | Lv1〜40 | 初期スポーン地点から100ブロックごとに+1。y=0より深い地下は最大+5 |
| ネザー | Lv35〜60 | ネザーでの距離×8（オーバーワールド換算）250ブロックごとに+1 |
| エンド | Lv70〜85 | 中央の島はLv70、外側の島ほど高い（800ブロック先から400ブロックごとに+1） |
| エンダードラゴン | Lv200固定 | |

- すべての敵対モブの移動速度は1.5倍（`monsterSpeedMultiplier`）。ドラゴンは体力3600（サーバーの人数で増える。下の「エンダードラゴン」参照）

レベルごとの強さ：

| Lv | 体力 | 攻撃力 | 爆発 |
|---|---|---|---|
| 1 | ×3.00 | ×1.00 | ×1.00 |
| 20 | ×7.07 | ×3.02 | ×1.51 |
| 40 | ×11.51 | ×5.20 | ×2.05 |
| 60 | ×16.12 | ×7.44 | ×2.61 |
| 80 | ×20.90 | ×9.73 | ×3.18 |
| 100 | ×25.85 | ×12.08 | ×3.77 |
| 150 | ×38.95 | ×18.20 | ×5.30 |
| 200 | ×53.11 | ×24.67 | ×6.92 |

- 体力 ×3×(1＋0.07(Lv−1)＋0.00007(Lv−1)²)（攻撃側と同じく3倍スケール。バニラの最大体力の上限1024は外してある）、攻撃 ×(1＋0.105(Lv−1)＋0.00007(Lv−1)²)。プレイヤーの体力（Lv199で500）に合わせた伸びで、どのレベルでも「同じレベルの敵は近接で5〜6発、レベル相応の防具なら敵の攻撃を10発ほど耐える」くらいになるよう決めてあります。パネルの攻撃力にある程度振った人がちょうどこの発数（振っていなければ1発ほど多い）（設定 `healthGrowthLinear/Square`・`damageGrowthLinear/Square`）
- 攻撃力は近接・矢・火の玉などすべてに掛かります。クリーパーの爆発も他の攻撃と同じだけ伸びます（TNTなど他の爆発は伸びを抑えてあります）
- 目安（難易度ノーマル）：Lv55のエンダーマンの一撃は素で約48、Lv110だと約93（ネザライト一式で約27、体力約290に対して）
- 職業の経験値は敵の最大体力に比例するので、遠くの強い敵ほど多くもらえます。バニラの経験値オーブも +2%/Lv
- 頭上に「Lv・名前・体力バー」（照準を合わせた敵と最近攻撃した敵は名前と数値つき）。受けたダメージは白い帯が遅れて減ります
- ダメージ数字：通常＝白、会心＝金「!」付き、魔法＝紫、炎＝橙、毒＝緑、回復＝緑「+」、プレイヤーの被ダメージ＝赤

### エリート個体

普通の敵の8%（設定 `eliteChance`）が**特性を持ったエリート**として出現します。特性はLv59までは1つ、Lv60〜129で2つ、Lv130以上で3つ。ボス・ボスの手下・クリーパー・シュルカー・ウォーデン・エルダーガーディアンはエリートになりません。

- 名前の前に【特性】が付き、遠くからでも常に名前が表示される。体が15%大きく、足元に特性の色の紋章、体の周りに特性ごとのオーラ
- 体力×2.5、攻撃×1.25。宝石が3倍、回復薬が2倍落ちやすい（倒すまでが長い分、職業経験値も体力に比例して多い）
- **初見殺しになる特性は入れていない**：見て分かり、対処できるものだけ（自爆・ダメージ反射・瞬間移動・透明化・即死・大量召喚・毒の床などはなし）

| 特性 | 効果 | 対処 |
|---|---|---|
| 鉄壁 | 受けるダメージ−35% | 時間をかける・強いスキルで |
| 俊敏 | 移動速度+30% | 足止め・距離に注意 |
| 剛力 | 攻撃+40%、移動−10% | 遅いので距離を取る |
| 再生 | 3秒攻撃されないと毎秒最大HPの3%回復 | 攻撃を途切れさせない |
| 吸血 | 与えたダメージの25%回復（赤い線が出る） | 被弾を減らす |
| 分裂 | 倒すと小さな2体に分かれる（体力3割、ドロップなし） | 範囲攻撃で |
| 号令 | 周り8ブロックの敵の攻撃+20%（金の線でつながる、頭上に紋章） | 先に倒す |
| 結界 | 魔法ダメージ半減 | 物理で |

### 亡者の冒険者（洞窟限定）
オーバーワールドの洞窟（y40未満・空が見えない場所）で自然湧きするモンスターの約25%が、かつての冒険者のなれの果て「亡者の冒険者」に置き換わる（`revenantChance`、0で無効）。洞窟のモンスター上限は普段どおりなので、全体の数は増えない。

- **湧き方**：74%は1体（戦士・魔導士・弓兵・盗賊のどれか）。18%は攻撃役＋神官の2体。8%は戦士・魔導士・弓兵か盗賊・神官の4人パーティ。神官は単独では出ない。
- **強さ**：ゾンビと同じ攻撃力のまま、体力は1.5倍（30）。武器はレベルに応じた職業の武器を持つ（ほかのモンスターの装備と同じく、威力は一部だけ反映）。ゾンビ化・子供・建築や掘削はなし。
- **技はすべて予兆つき**：
  - 戦士：突進（地面に赤い直線。0.8秒後に突進、攻撃力×1.3）、薙ぎ払い（扇形の予兆から0.7秒後、×1.5）
  - 魔導士：6〜14ブロックの距離を保ち、火球（足元に詠唱陣、着弾点に赤い円。円が満ちたころに着弾、×1.3＋着火）
  - 弓兵：普段は弓で射撃。時々レーザーサイトで1.2秒狙ってから強射（×1.6）
  - 神官：プレイヤーから距離をとり、仲間の後ろにつく。仲間が傷つくと1秒の詠唱のあと、10ブロック内の仲間を最大体力の15%回復
  - 盗賊：移動速度+25%。短い直線の予兆から0.5秒後にダッシュ斬り（×1.2）
- **ドロップ**：腐肉に加え、プレイヤーが倒すと職業ごとの品（戦士：鉄、魔導士：ラピスラズリ、弓兵：矢、神官：金塊、盗賊：エメラルドか金塊）。

### 防御力（RPG式）

バニラの防具計算（大ダメージほど防具が効かず、防御力20で頭打ち）を、RPG向けの計算に置き換えています。

```
防御値 = 防御力×2 ＋ 防具強度×2   （職業・パネル・鍛冶の防御力も含む）
軽減率 = 防御値 ÷ (防御値 ＋ K)     K = プレイヤー80／敵80
```

- 攻撃の大きさに関係なくいつも同じ割合で減り、上限なく効き続けます（100%にはならない）
- バニラの上限（防御力30・防具強度20）は無視して、超えた分も計算に入ります
- **防具のランク補正（プレイヤーのみ）**：上位の防具ほど防御力が上乗せされます。4部位すべてで 鉄＋13／金＋34／ダイヤ＋44／ネザライト＋66（頭・胴・脚・足に配分、部位ごとに付く。革・チェーン・銅は＋0）。上乗せは防具そのものに付くので、防具の説明欄の防御力は上乗せ込みの本当の値（ネザライトの胸当て 8→28 など）。一式の防御力は 鉄28／金45／ダイヤ64（＋防具強度8）／ネザライト86（＋防具強度12）。敵の装備には付きません
- **レベルで防御力は伸びません**：耐久はレベルで伸びる体力が受け持ち、防御は防具（とパネル・鍛冶・宝石）で決まります
- 一式の目安（プレイヤー・Lv1）：革 約15%／銅 約20%／鉄 約41%／金 約53%／ダイヤ 約64%／ネザライト 約71%。レベルでは変わりません。ステータス画面に「被ダメ軽減」として表示
- 目安：Lv100のゾンビ（素の一撃 約70）に対して、ダイヤ一式のLv100ファイター（体力約260）は約10発耐えます
- 敵の装備は K=80 なので効き目は半分ほど（ダイヤ一式の敵で約41%）。敵の武器の攻撃力は15%だけ加算（武器はプレイヤーと同じ3倍スケールなので、元のスケールで45%分。素材の倍率も45%分：ネザライトなら×1.2）
- **体力に合わせた回復と環境ダメージ**：体力が数百になるので、バニラの量（体力20向け）は「最大体力÷20」倍になります。満腹での自然回復・再生・治癒のポーションなどの回復と、敵のいないダメージ（落下・溶岩・炎・溺れ・空腹・毒・ウィザー・サボテンなど）。奈落と /kill はそのまま。MODの回復（スキル・宝石・回復薬）は今までどおりの量
- エンチャントの防護と耐性エフェクトはこのあとにバニラどおり掛かります。スキルの魔法も防具で減ります（毒など防具を無視する攻撃は今までどおり）
- 設定：`rpgArmor`（オフでバニラ式）、`playerArmorReductionK`、`monsterArmorK`、`monsterWeaponEffect`

### 敵の装備

エンダーマン・エンダードラゴン・ウィザーなどのボス以外の敵対モブは、レベルに応じてランダムに防具と職業の武器を持って出現します（ドロップはしません）。クリーパーは防具を着ません。クモのように見た目に表示できない敵も、防具の防御力と武器の攻撃力は内部でちゃんと効いています。

- 防具は各部位 25〜65%（Lvが高いほど多い、Lv150で最大）、武器は 50〜85%（Lv130で最大）
- 近接の敵は剣・短剣・メイス・ハンマー・杖のどれか、スケルトンは弓（射撃を続けます）。弓・クロスボウ・トライデントで撃つ敵（ピラジャー、ピグリン、ドラウンドなど）とウィッチの手はそのまま
- 素材：Lv1〜29 銅・鉄／Lv30〜66 鉄・銅・金／Lv67〜104 鉄・ダイヤ・金／Lv105〜134 ダイヤ・鉄／Lv135〜 ネザライト・ダイヤ（ネザライトはLv135以降のみ。装備の段階は敵のレベルの1.5倍かけて上がり、Lv150で以前のLv100相当）
- **防具は見た目に表示しません**：防具は内部で着ていて（防御力はそのまま効く）、見た目は素のゾンビやスケルトンのまま。武器は今までどおり見えます。カボチャ・頭ブロックも見えます。設定 `showMonsterArmor` をオンにすると防具も表示
- 設定 `monsterEquipment` でオフにできます

### 蘇生MOD（Resurrection）との連携

Resurrection を一緒に入れると、ダウン中のプレイヤーは敵に狙われなくなります（入れていなければ何もしません）。

- 敵はダウン中の人をターゲットに選ばず、すでに狙っていた敵も手を離して他のプレイヤーを探す（ゾンビの壁越し索敵、スケルトン、ピグリンなど全部）
- キングスライムはダウン中の人を狙わず、ダウン中の人の近くには出現しない
- ドラゴンはダウン中の人を攻撃対象に選ばず、羽ばたきや怒りの衝撃波でも吹き飛ばさない（奈落に落とされない）
- 蘇生されたら、また普通に狙われる

### エンダードラゴン（3段階のボス戦）

すべての大技は先に予兆が出ます（地面の紋章、範囲の輪、赤い線、咆哮）。ボスバーに「Lv100・形態」が表示され、色も変わります。

| 形態 | 体力 | 追加される攻撃 |
|---|---|---|
| 第一形態 | 60%以上 | 紋章を出した地点に火の玉を連射（3発） |
| 第二形態 | 60〜25% | 連射4発、止まっている間の翼の突風（範囲の輪→吹き飛ばし）、追尾する虚空の弾（浮遊）、虚空からファントムを召喚 |
| 最終形態 | 25%未満 | 連射6発、赤い線で狙った相手に突進、紋章の位置に空からドラゴンブレスの雨。形態が変わるときは衝撃波 |

ドラゴンの攻撃はブレスも含めて×8（プレイヤーの体力がLv199で500まで伸びるのに合わせた値。ブレスは防具を無視するのでレベルの伸びは使わず固定。設定 `dragonDamageMultiplier`）。

- **体力は人数で増える**：3600 ×（1＋0.6×(サーバーの人数−1)）。6人なら14400（攻撃力が3倍スケールで、さらにLv199で以前の約2倍になったのに合わせて。設定 `dragonHealthMultiplier`）。観戦者は数えず、人が出入りしたら残りの割合を保って変化。1024の上限を超える分はキングスライムと同じく、受けるダメージを割って再現（ダメージ数字は割る前の値）
- **1回に削れる量に上限**：止まり木に降りている1回、または降りてくるまでの1回の飛行（最長30秒）ごとに、削れるのは最大体力の20%まで。降りている間に上限に達すると盾の音とともにすぐ飛び立つ。飛行中に達すると、次に降りるまで攻撃が通らない（画面下に表示）。どんなに火力があっても全部の形態を見ることになる
- 設定：`dragonHealthPerPlayer`（0.6）、`dragonMaxShare`（0.2、0で上限なし）

### ブラッドムーンのボス（キングスライム／ゴーレム）

- 毎朝「N日目」と表示されます（予告はなし）
- **5日ごと**（5日目・10日目…）の夜はブラッドムーン：空と月が赤くなり、ベッドで眠れず、通常の敵の湧きは2割に減ります
- 日没と同時に、オーバーワールドにいるプレイヤーからランダムに1人選び、その20〜30ブロック先の地上（地下にいれば周りの開けた場所）に**キングスライム**か**ゴーレム**（50%ずつ、`golemChance`）が現れます。全員に「○○の近くに現れた」と通知
- 朝までに倒せなければ地面に沈んで去ります（報酬なし）

| | |
|---|---|
| レベル | 一番高い職業レベル＋0（`levelBonus`） |
| 体力 | 800 ×（敵と同じレベルの伸び）×（1＋0.6×(サーバーの人数−1)）。人数が変わったら残りの割合を保って変化。バニラの最大体力上限（1024）を超える分は、表示上の体力を1000にして受けるダメージを同じ比率で割る（物理・魔法・矢・毒など全部同じ。ダメージ数字は割る前の値で表示） |
| 被ダメ上限 | 1発で最大体力の20%まで（防具の前） |
| 報酬 | 倒したときに攻撃した人・近く（48ブロック）にいた人全員に **スキルの書×5**。右クリックでスキルポイント+1（しゃがみ右クリックでまとめて）。職業を変えてもポイントは残ります |

**リズム**：素早く跳ねて追いかけ → 技を2つ（後半は3つ）連続で出す → **ヘトヘト**（約3秒へたり込み、被ダメ1.5倍、足元に金の輪・汗・ボスバーに「チャンス！」）→ また追いかける。叩きつけの後にも短い隙、分裂の咆哮の後もヘトヘトになります。

技（すべて予兆つき・回避可能）：
- **叩きつけ**：着地点に赤い円 → 大ジャンプ → 円の中にダメージ＋地面を這う衝撃波の輪（ジャンプで避けられる）→ 短いダウン（被ダメ1.3倍）
- **連続ホップ**：小さな円つきの低いジャンプを4回（後半6回）連続で追ってくる。着地ごとに小さな波紋
- **突進**：進路に赤い帯 → 一直線に滑ってくる（横へ避ける）。通った跡にベタベタの水たまり（踏むと鈍足）。**壁にぶつけると3.5秒ダウン（被ダメ1.5倍）**で最大のチャンス
- **スライムの雨**：膨らんで空へ打ち上げ → 各プレイヤーの足元と周りに青い円 → 順番に降ってくる
- **スライム弾**：遅い弾を3発（後半5発）。当たると移動速度低下
- **分裂**：体力75%・50%・25%で一回り小さくなり子スライムを吐き出す（2匹＋人数ぶん）
- **後半（50%以下）**：紫に光って速くなり、3連続の叩きつけ、**地鳴らし**（3回跳ねて足踏み→リズムよく広がる輪を3回ジャンプ）、**吸収**（子スライムを引き寄せて回復。先に倒せば防げる、吸収中は被ダメ1.3倍）が加わる
- 体当たりは跳ねて乗ってきたときだけ当たるので、近接職でも横で殴り続けられます

#### ゴーレム

高さ約6ブロックの黒い石の巨人。体のひびと胸の核が赤く光る。レベル・体力の計算（`golemBaseHealth`）・被ダメ上限・報酬・朝に去る（崩れて地面に還る）はキングスライムと同じ。

**リズム**：ゆっくり歩いて追ってくる（近くにいると殴る）→ 技を2つ（後半は3つ）連続 → **オーバーヒート**（約3.5秒ひざをついて核がむき出し、被ダメ1.5倍、足元に金の輪・湯気・ボスバーに「チャンス！」）→ また追いかける。叩きつけの後も短い隙（被ダメ1.3倍）。

技（すべて予兆つき・回避可能）：
- **叩きつけ**：両腕を振り上げる → 周りに赤い円 → 円の中にダメージ＋地面を這う衝撃波（ジャンプで避けられる）
- **岩投げ**：地面から岩をはがして頭上に掲げ、狙ったプレイヤーへ投げる。着地点に赤い円、着弾で破片が飛び散る（後半は2個）
- **地割れ**：片足を上げて足踏み → プレイヤーに向かって赤い帯 → 帯に沿って岩のトゲが順に突き出る（横に避ける）
- **突進**：進路に赤い帯 → 一直線に走る。**壁にぶつかると3.5秒ダウン（被ダメ1.5倍）**
- **薙ぎ払い**：近くに張り付いていると、腕を大きく引いて周りをなぎ払う（大きく吹き飛ばす）。予兆の円を見て離れる
- **落石**：咆哮 → 全員の足元と周りに円 → 空から岩が順に落ちてくる
- **跳躍**：歩いて行けない場所（塔の上など）にいる相手には、着地点に円を出して飛びかかる
- **後半（50%以下）**：核が赤熱して速くなり、叩きつけが**3連続の地震**（広がる輪を3回ジャンプ）に
- **岩の鎧**：体力50%と25%で、周りに光る岩の柱を3本（＋人数分、最大6本）立てる。柱が1本でも残っている間は**被ダメ半分**（体がオレンジの渦に包まれ、柱から光の筋が伸びる）。柱を全部壊すと鎧が砕けて3秒よろめく（被ダメ1.5倍）。柱の体力は 15 ×（敵と同じレベルの体力の伸び）：同じレベルのプレイヤーで3発ほど

設定（`rpgmod-mobs.toml` の `[bloodMoon]`）：`enabled`, `everyNthDay`, `spawnRate`, `dayTitle`, `kingSlimeBaseHealth`, `golemBaseHealth`, `golemChance`, `healthPerPlayer`, `levelBonus`, `maxHitShare`, `rewardBooks`

### 設定

`config/rpgmod-mobs.toml`：レベルの決め方（`levelsFromPlayers`, `playerLevelBonusMin/Max`）、移動速度（`monsterSpeedMultiplier`）、ゾンビの索敵範囲（`monsterSenseRange`）、場所方式のレベル範囲・距離、体力と攻撃力の伸び（`healthA/B`, `damageGrowthA/B`）、爆発の伸び、賢いAIのオン/オフ、ブロック破壊のオン/オフ（`breakBlocks`）、ドラゴンの体力・攻撃倍率、3段階ドラゴンのオン/オフ。

## マルチプレイ

- 鍛冶の状態はプレイヤーごとにサーバー側で管理（同時に何人でも可）
- クライアントは入力（どこで止めたか）だけを送信し、温度・加工値・品質・オプションはサーバーで決定
- バーのトークン、時間の妥当性チェック、連打制限で不正・二重実行を防止
- GUIを閉じる・ログアウト・離れると、その時点の出来で完成（加熱前なら素材を返却）

## 数値の調整

`config/rpgmod-synced.toml`（サーバーの値がクライアントにも同期されます） で全ての数値（温度範囲、威力、バー速度、判定幅、品質しきい値など）を変更できます。

バランスはシミュレーションで確認しています：

```
javac -d out $(find src/main/java/com/jo112ss/rpgmod/smithing/core -name '*.java') tools/sim/BalanceSim.java
java -cp out BalanceSim
```

目標値は「実際のルールで仮想的に鍛冶をした結果」から作るので、到達不可能な目標は出ません。剣は約9割の確率で中央が最大・両端が小さめになります。

## ビルド

```
./gradlew build
```

`build/libs/rpgmod-<version>.jar` を `mods` フォルダへ。Java 25 が必要です。

## 武器の追加

`ForgeableWeapons.ALL` に1行追加するだけで、新しい武器（斧など）を鍛冶対象にできます。部位の数と作業量の配分は `TargetProfile`、GUIの画像は `textures/gui/` で指定します。
