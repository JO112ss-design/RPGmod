# RPG Mod

Minecraft **26.3 / NeoForge** 向けのRPG系mod。「鍛冶ミニゲーム」と「職業システム（土台）」を実装しています。

## 鍛冶ミニゲーム

**鍛冶台**（鉄インゴット×3・鉄ブロック・石レンガ×2・かまど）を右クリックで開きます。

1. **作るものを選ぶ** — 武器6種（剣・短剣・メイス・ハンマー・魔法の杖・弓）と防具4種（ヘルメット・チェストプレート・レギンス・ブーツ）× 銅/鉄/金/ダイヤ。素材は通常クラフトと同じ数
2. **加熱** — 左右に動くバーを止めて初期温度を決める。右ほど高温（威力が高く、バーが遅い）
3. **部位を選ぶ** — 切先・前部・中央・後部・根元をクリック（または 1〜5 キー）
4. **鍛打** — バーを止める（クリック / スペース）。止めた位置で威力が変わる：中央の赤＝強 100% / 黄＝中 75% / 外側の緑＝弱 40% / 枠外＝ミス 0%
   - 叩いた部位に100%、左右の隣に25%
   - 1回叩くごとに温度 −5。温度20以下で強制終了
5. **冷却** — 温度 −15。威力を落として微調整したいときに
6. **仕上げる** — 誤差（不足は×1.0、超過は×1.5で減点）から品質が決まる

| 品質 | オプション数 | 色 |
|---|---|---|
| 普通 | 1 | 灰 |
| 上質 | 2 | 青 |
| 希少 | 3 | 紫 |
| 伝説 | 4 | 金 |

素材が良いほど難しくなります（バーが速く、強・中・弱の幅が狭く、品質判定が厳しい）。難易度：銅×0.85 / 鉄×1.0 / 金×1.1 / ダイヤ×1.2（設定で変更可）。

オプション（重複なし・数値ランダム）
- 武器: 攻撃力、攻撃速度、会心率、会心ダメージ、防御貫通、ボス特効、最大HP、防御力、移動速度、耐久値、獲得経験値、ノックバック耐性、最大MP（+10〜25）、MP回復（+8〜20%）、魔法威力・詠唱短縮（杖のみ）
- 防具: 防御力、防具強度、最大HP、移動速度、ノックバック耐性、耐久値、獲得経験値、被ダメージ軽減、ボス耐性、魔法威力、詠唱短縮、最大MP（+5〜12）、MP回復（+4〜10%）（複数部位で重ねがけ可）

- 武器の効果はメインハンドに持っている間、防具の効果は装備している間だけ有効
- **会心**：バニラの落下会心とは別枠。会心率＝職業＋鍛冶武器（合計で1回抽選）、倍率＝1.5＋会心ダメージ。近接・矢・スキル・魔法すべてに適用し、落下会心とは掛け算で重複
- 通常クラフトの武器はオプションなし
- ダイヤ → ネザライトへのアップグレードで品質・オプションを引き継ぐ（武器・防具とも）
- 品質・オプション・製作者はアイテムに保存され、受け渡しやサーバー再起動でも消えない


## 職業システム（土台）

8職業から、ワールドに初めて入ったときに1つだけ選びます（選び直しは管理者コマンドのみ）。

| 職業 | スキルが使える武器 |
|---|---|
| ファイター | 剣・ハンマー |
| レンジャー | 弓 |
| パラディン | メイス・剣 |
| ウィザード | 魔法の杖 |
| ヒーラー | 魔法の杖・メイス |
| アサシン | 短剣 |
| エンチャンター | 魔法の杖・短剣 |
| ギャンブラー | 短剣・弓 |

- **初期装備**：職業を選ぶと銅の武器（ウィザードは杖、レンジャーは弓、他は近接武器：ファイター剣／パラディン・ヒーラーはメイス／アサシン・エンチャンター・ギャンブラーは短剣）と鍛冶台1つを受け取る
- **成長**：モブを倒すとEXP（最大HPに比例、ボスは3倍・キングスライムは等倍、近くの仲間にも同量）。レベルごとにスキルポイント+1（最大Lv100）。必要EXP＝(15＋2.5×Lv＋Lv²÷8)×序盤補正。序盤補正はLv1で×3、Lv40で×1に向けてなだらかに下がる（同じくらいの敵で1レベルあたり約2.5体→Lv20以降は約6体）。Lv40までの合計は約7600
- **スキルパネル**：職業ごとのハニカム盤面（半径7・169マス）。中央から隣り合うマスを解放。ホイールで拡大縮小、ドラッグで移動
  - ステータスのマス：内側（1〜3周）1pt、中間（4〜5周）は効果1.5倍で2pt、外側（6〜7周）は2倍で3pt
  - スキルは2〜6周目に角度をずらして散らばり（2〜4pt）、必殺技は外周の反対側に2つ（5pt）
  - 攻撃力・魔法攻撃力・防御力はレベルアップとパネルの両方で強く伸びます（敵のレベルに合わせて2倍に強化）
  - 最大体力はレベルアップで伸び、Lv100でパラディンは60、ファイター・ギャンブラーは40、アサシン・レンジャー・ヒーラー・エンチャンターは30（パネルの体力マス +2〜4 は別に加算）。ウィザードは伸びません
  - 旧データはレベルが「×2−1」に換算され、ポイントは全額返却
- **MP**：時間で自然回復。30秒間攻撃も被弾もしないと回復が3倍（HUDに「MP回復 ×3」）。設定 `restRegenDelay`・`restRegenMultiplier`
- **スキル**：Z・X でスキル1・2、C で必殺技（キー設定で変更可）。パネルで覚えたスキルを付け替え可能。職業の武器を持っているときだけ発動、クールタイムとMPあり
- **ウィザード**：杖ごとに呪文4枠。V長押しで円形メニューから選び、右クリックで詠唱
- **画面**：K で職業メニュー（ステータス／スキルパネル／スキル／呪文）。画面右下にレベル・EXP・MP・スキルのクールタイム
- スキルの数値は `JobDefs`、当たり判定と動きは `SkillExecutor`、見た目は `client/fx/`

### スキルのダメージ計算

```
スキルダメージ = 攻撃力 × スキル倍率 × (1 + スキル威力%)
```

- **攻撃力**（剣・短剣・メイス・ハンマー・弓の職業）= 素手1 ＋ 武器の攻撃力 ＋ 自身の攻撃力 → ×（1 ＋ 鍛冶の攻撃力%）＋ 力のポーション。弓は「矢を引き絞った攻撃力 6 ＋ 素材ボーナス」を武器の攻撃力として数えます
- **魔法攻撃力**（ウィザード・ヒーラー・エンチャンターのスキルと呪文）=（1 ＋ 杖の魔法攻撃力 ＋ 自身の魔法攻撃力）×（1 ＋ 鍛冶の魔法威力%）。杖：銅4／鉄5／金6／ダイヤ7／ネザライト8
- **自身の攻撃力・魔法攻撃力**は職業の初期値＋レベルアップ＋スキルパネルで増えます（レベルごとに+0.06〜0.08、パネルの1マス +0.4〜0.8）
- **スキル倍率**：強撃300%、メテオ300%、ヒール（回復）90% など。職業画面のスキル説明に「威力 攻撃力×300%（今 21.0）」と表示
- そのあと会心・防御貫通・ボス特効・敵の防具（魔法は無視）が掛かります
- MP回復系のスキルは攻撃力に関係なく、スキル威力%だけで増えます
- **弓の通常射撃**にも自身の攻撃力（レベル・パネル・力のポーション／付与・鬨の声など。弱体化はマイナス）が乗ります。引き絞り具合に比例し、満タンで「ステータス画面の攻撃力」と同じダメージになります（そのあと会心）
- **エンチャンターのバフ**（付与・加速・炎の付与・大付与）の効果時間は魔法攻撃力で増減：表記の時間 ×（魔法攻撃力 ÷ 10）、0.5〜3倍。スキル説明に今の効果時間を表示。設定 `enchanterBuffReferenceAttack` / `enchanterBuffMinMultiplier` / `enchanterBuffMaxMultiplier`
- ファイター・レンジャー・パラディン・アサシン・ギャンブラーのスキル消費MPは半分（ウィザード・ヒーラー・エンチャンターは据え置き）
- ウィザード以外の職業の攻撃スキル倍率は2倍に調整済み（回復・MP回復・移動系は据え置き。聖なる波・カード投げ・ギャンブルの回復/MP/自爆分は倍率が上がっても以前と同じ量）

### スキルの演出と範囲

全72スキルに専用の演出があります。自作の発光パーティクル（加算合成）で、魔法陣・斬撃の弧・衝撃波・氷片・羽・コインなどを描きます。サーバーは「何が起きたか」だけを送り、パーティクルはクライアントで時間差アニメーションするので、マルチでも通信は軽いです。ビデオ設定の「パーティクル」を減らすと演出の量も減ります。

| 種類 | 例 | 当たり方 |
|---|---|---|
| 扇形 | 強撃（半径4.5・左右65°）、盾打ち（4）、毒刃（4） | 前方の扇形に一度 |
| 周囲 | 旋風斬（4.5・2回ヒット）、フロストノヴァ（6） | 広がる波が届いた順にヒット |
| 衝撃波 | 大地割り（7） | 地面を走る衝撃波が通過した敵に |
| 狙い撃ち | マジックボルト（28・追尾）、裁きの一撃（8）、暗殺（12） | 照準に近い敵を自動で狙う |
| 着弾点 | メテオ（36先・半径5.5）、サンダー（28・連鎖3体）、アローレイン（32・半径5）、罠（14） | 見ている地面に予兆→時間差で着弾 |
| 設置 | 聖域（6・8秒）、罠（4秒） | その場に残り続ける |
| 移動 | ブリンク（10）、影歩き（敵の背後へ）、突進 | 壁や地面に埋まらない位置へ |

- 大技（メテオ・大地割り・審判など）は近くのプレイヤーの画面が揺れます
- 杖の詠唱中は足元に魔法陣が広がり、詠唱完了で光ります
- 会心とレベルアップにも専用の演出
- 管理者コマンド：`/rpgjob info|reset|set|level|exp <プレイヤー> ...`
- 設定：`config/rpgmod-jobs.toml`（`maxJobLevel` 最大レベル、EXP倍率、共有範囲など）

## 敵の強化

### 敵レベル

モンスターは出現したときにレベルが決まり、強くなります（一度決まったレベルはそのまま保存）。

- **標準**：オンラインのプレイヤーのうち一番高い職業レベル ＋0〜3（例：最高Lv31なら Lv31〜34）。エンダードラゴンはLv100固定
- 設定 `levelsFromPlayers = false` にすると、場所で決める方式になります：

| 場所 | レベル | 決まり方 |
|---|---|---|
| オーバーワールド | Lv1〜40 | 初期スポーン地点から100ブロックごとに+1。y=0より深い地下は最大+5 |
| ネザー | Lv35〜60 | ネザーでの距離×8（オーバーワールド換算）250ブロックごとに+1 |
| エンド | Lv70〜85 | 中央の島はLv70、外側の島ほど高い（800ブロック先から400ブロックごとに+1） |
| エンダードラゴン | Lv100固定 | |

- すべての敵対モブの移動速度は1.5倍（`monsterSpeedMultiplier`）。ドラゴンは体力600

レベルごとの強さ：

| Lv | 体力 | 攻撃力 | 爆発 |
|---|---|---|---|
| 1 | ×1.00 | ×1.00 | ×1.00 |
| 20 | ×1.57 | ×1.18 | ×1.04 |
| 40 | ×2.36 | ×1.42 | ×1.11 |
| 60 | ×3.35 | ×1.73 | ×1.18 |
| 80 | ×4.54 | ×2.10 | ×1.28 |
| 100 | ×5.93 | ×2.54 | ×1.38 |
| 110 | ×6.70 | ×2.78 | ×1.44 |

- 攻撃力は近接・矢・火の玉などすべてに掛かります。爆発は伸びを抑えてあり、クリーパー1体で即死しにくくしています
- 目安（難易度ノーマル）：Lv55のエンダーマンの一撃は素で約11.5（ダイヤ一式で約4.9）、Lv110だと素で約19（ネザライト一式で約7.3）
- 職業の経験値は敵の最大体力に比例するので、遠くの強い敵ほど多くもらえます。バニラの経験値オーブも +2%/Lv
- 頭上に「Lv・名前・体力バー」（照準を合わせた敵と最近攻撃した敵は名前と数値つき）。受けたダメージは白い帯が遅れて減ります
- ダメージ数字：通常＝白、会心＝金「!」付き、魔法＝紫、炎＝橙、毒＝緑、回復＝緑「+」、プレイヤーの被ダメージ＝赤

### 防御力（RPG式）

バニラの防具計算（大ダメージほど防具が効かず、防御力20で頭打ち）を、RPG向けの計算に置き換えています。

```
防御値 = 防御力×2 ＋ 防具強度×2   （職業・パネル・鍛冶の防御力も含む）
軽減率 = 防御値 ÷ (防御値 ＋ K)     K = プレイヤー40／敵80
```

- 攻撃の大きさに関係なくいつも同じ割合で減り、上限なく効き続けます（100%にはならない）
- バニラの上限（防御力30・防具強度20）は無視して、超えた分も計算に入ります
- 一式の目安（プレイヤー）：革 約26%／銅・鉄 約43%／ダイヤ 約58%／ネザライト 約62%。ステータス画面に「被ダメ軽減」として表示
- 敵の装備は K=80 なので効き目は半分ほど（ダイヤ一式の敵で約41%）。敵の武器の攻撃力は半分だけ加算
- エンチャントの防護と耐性エフェクトはこのあとにバニラどおり掛かります。魔法など防具を無視する攻撃は今までどおり無視
- 設定：`rpgArmor`（オフでバニラ式）、`playerArmorK`、`monsterArmorK`、`monsterWeaponShare`

### 敵の装備

エンダーマン・エンダードラゴン・ウィザーなどのボス以外の敵対モブは、レベルに応じてランダムに防具と職業の武器を持って出現します（ドロップはしません）。クリーパーやクモのように見た目に表示できない敵も、防具の防御力と武器の攻撃力は内部でちゃんと効いています。

- 防具は各部位 25〜65%（Lvが高いほど多い）、武器は 50〜85%
- 近接の敵は剣・短剣・メイス・ハンマー・杖のどれか、スケルトンは弓（射撃を続けます）。弓・クロスボウ・トライデントで撃つ敵（ピラジャー、ピグリン、ドラウンドなど）とウィッチの手はそのまま
- 素材：Lv1〜19 銅・鉄／Lv20〜44 鉄・銅・金／Lv45〜69 鉄・ダイヤ・金／Lv70〜89 ダイヤ・鉄／Lv90〜 ネザライト・ダイヤ（ネザライトはLv90以降のみ）
- 設定 `monsterEquipment` でオフにできます

### 賢い敵（Enhanced AI風）

行動パターンはレベルに関係なく全員が持っています（レベルで変わるのは命中精度・連射速度・掘る速さ・導火線の長さなどの強さだけ）。

| 敵 | 行動 |
|---|---|
| ゾンビ・ハスク | 索敵範囲128ブロック。届かない相手には足元にブロックを積んで登る（1ブロック約0.3秒）／穴や液体に橋をかける／壁を掘って進む（土0.6秒・石1.2秒・深層岩2秒ほど、高Lvほど速い。黒曜石・岩盤・チェストなど中身のあるブロックは掘らない）。積んだブロック（ネザーではネザーラック、エンドではエンドストーン）は残ります |
| ゾンビの左手 | 4体に1体がアイテムを持つ：エンダーパール（離れると投げて距離を詰める）、釣り竿（バニラの釣り竿と同じ引き寄せ）、TNT（投げてくる） |
| スケルトンなど弓の敵 | 動く相手の先を狙う（Lvが高いほど正確）、射程15→最大30ブロック、Lvが上がるほど連射が速い、近づかれると飛び退く、弓を向けられると横に避ける、3連射（20%）、効果付きの矢（30%：鈍化・弱体化・毒・盲目）、火矢（25%） |
| クリーパー | 壁越しでも近くにいれば起爆、たどり着けないと壁を爆破して道を開ける、Lvが上がると導火線が短くなる、5%は帯電クリーパー |
| クモ | 足元にクモの巣を吐く（5秒で消える） |
| エンダーマン | 攻撃されると背後にテレポートして反撃 |
| 共通 | プレイヤーに攻撃された敵は、近くの同じ種類の敵を呼ぶ（中立モブを除く） |
| ブレイズ | 火の玉の先読み（Lvで正確に）、ときどき4発目、近づくと足元に予兆の輪→炎の衝撃波（燃焼＋吹き飛ばし） |
| ガスト | 火の玉の先読み、ときどき続けて2発追撃 |
| ウィザースケルトン・ピグリンブルート | 赤い予兆のあと、数ブロック先から飛びかかる |
| ホグリン・ゾグリン | 鼻を鳴らす予兆のあと、一直線に突進して跳ね飛ばす |
| マグマキューブ | 予兆のあと大ジャンプで飛びかかり、着地で炎の衝撃波 |
| ゾンビピグリン | 怒らせると、ゾンビと同じくブロックを積んで登り、壁を掘って追ってくる |

ブロックの破壊はゲームルール `mobGriefing` にも従います。

### エンダードラゴン（3段階のボス戦）

すべての大技は先に予兆が出ます（地面の紋章、範囲の輪、赤い線、咆哮）。ボスバーに「Lv100・形態」が表示され、色も変わります。

| 形態 | 体力 | 追加される攻撃 |
|---|---|---|
| 第一形態 | 60%以上 | 紋章を出した地点に火の玉を連射（3発） |
| 第二形態 | 60〜25% | 連射4発、止まっている間の翼の突風（範囲の輪→吹き飛ばし）、追尾する虚空の弾（浮遊）、虚空からファントムを召喚 |
| 最終形態 | 25%未満 | 連射6発、赤い線で狙った相手に突進、紋章の位置に空からドラゴンブレスの雨。形態が変わるときは衝撃波 |

ドラゴンの攻撃はブレスも含めて×1.5（ブレスは防具を無視するため控えめ）。

### ブラッドムーンとキングスライム（中ボス）

- 毎朝「N日目」と表示されます（予告はなし）
- **10日ごと**（10日目・20日目…）の夜はブラッドムーン：空と月が赤くなり、ベッドで眠れず、通常の敵の湧きは2割に減ります
- 日没と同時に、オーバーワールドにいるプレイヤーからランダムに1人選び、その20〜30ブロック先の地上（地下にいれば周りの開けた場所）に**キングスライム**が現れます。全員に「○○の近くに現れた」と通知
- 朝までに倒せなければ地面に沈んで去ります（報酬なし）

| | |
|---|---|
| レベル | 一番高い職業レベル＋0（`levelBonus`） |
| 体力 | 800 ×（敵と同じレベルの伸び）×（1＋0.6×(サーバーの人数−1)）。人数が変わったら残りの割合を保って変化。バニラの最大体力上限（1024）を超える分は、表示上の体力を1000にして受けるダメージを同じ比率で割る（物理・魔法・矢・毒など全部同じ。ダメージ数字は割る前の値で表示） |
| 被ダメ上限 | 1発で最大体力の20%まで（防具の前） |
| 報酬 | 倒したときに攻撃した人・近く（48ブロック）にいた人全員に **スキルの書×5**。右クリックでスキルポイント+1（しゃがみ右クリックでまとめて）。職業を変えてもポイントは残ります |

**リズム**：素早く跳ねて追いかけ → 技を2つ（後半は3つ）連続で出す → **ヘトヘト**（約3秒へたり込み、被ダメ1.5倍、足元に金の輪・汗・ボスバーに「チャンス！」）→ また追いかける。叩きつけの後にも短い隙、分裂の咆哮の後もヘトヘトになります。

技（すべて予兆つき・回避可能）：
- **叩きつけ**：着地点に赤い円 → 大ジャンプ → 円の中にダメージ＋地面を這う衝撃波の輪（ジャンプで避けられる）→ 短いダウン（被ダメ1.3倍）
- **連続ホップ**：小さな円つきの低いジャンプを4回（後半6回）連続で追ってくる。着地ごとに小さな波紋
- **突進**：進路に赤い帯 → 一直線に滑ってくる（横へ避ける）。通った跡にベタベタの水たまり（踏むと鈍足）。**壁にぶつけると3.5秒ダウン（被ダメ1.5倍）**で最大のチャンス
- **スライムの雨**：膨らんで空へ打ち上げ → 各プレイヤーの足元と周りに青い円 → 順番に降ってくる
- **スライム弾**：遅い弾を3発（後半5発）。当たると移動速度低下
- **分裂**：体力75%・50%・25%で一回り小さくなり子スライムを吐き出す（2匹＋人数ぶん）
- **後半（50%以下）**：紫に光って速くなり、3連続の叩きつけ、**地鳴らし**（3回跳ねて足踏み→リズムよく広がる輪を3回ジャンプ）、**吸収**（子スライムを引き寄せて回復。先に倒せば防げる、吸収中は被ダメ1.3倍）が加わる
- 体当たりは跳ねて乗ってきたときだけ当たるので、近接職でも横で殴り続けられます

設定（`rpgmod-mobs.toml` の `[bloodMoon]`）：`enabled`, `everyDays`, `spawnRate`, `dayTitle`, `kingSlimeBaseHealth`, `healthPerPlayer`, `levelBonus`, `maxHitShare`, `rewardBooks`

### 設定

`config/rpgmod-mobs.toml`：レベルの決め方（`levelsFromPlayers`, `playerLevelBonusMin/Max`）、移動速度（`monsterSpeedMultiplier`）、ゾンビの索敵範囲（`zombieFollowRange`）、場所方式のレベル範囲・距離、体力と攻撃力の伸び（`healthA/B`, `damageGrowthA/B`）、爆発の伸び、賢いAIのオン/オフ、ブロック破壊のオン/オフ（`breakBlocks`）、ドラゴンの体力・攻撃倍率、3段階ドラゴンのオン/オフ。

## マルチプレイ

- 鍛冶の状態はプレイヤーごとにサーバー側で管理（同時に何人でも可）
- クライアントは入力（どこで止めたか）だけを送信し、温度・加工値・品質・オプションはサーバーで決定
- バーのトークン、時間の妥当性チェック、連打制限で不正・二重実行を防止
- GUIを閉じる・ログアウト・離れると、その時点の出来で完成（加熱前なら素材を返却）

## 数値の調整

`config/rpgmod-synced.toml`（サーバーの値がクライアントにも同期されます） で全ての数値（温度範囲、威力、バー速度、判定幅、品質しきい値など）を変更できます。

バランスはシミュレーションで確認しています：

```
javac -d out $(find src/main/java/com/jo112ss/rpgmod/smithing/core -name '*.java') tools/sim/BalanceSim.java
java -cp out BalanceSim
```

目標値は「実際のルールで仮想的に鍛冶をした結果」から作るので、到達不可能な目標は出ません。剣は約9割の確率で中央が最大・両端が小さめになります。

## ビルド

```
./gradlew build
```

`build/libs/rpgmod-<version>.jar` を `mods` フォルダへ。Java 25 が必要です。

## 武器の追加

`ForgeableWeapons.ALL` に1行追加するだけで、新しい武器（斧など）を鍛冶対象にできます。部位の数と作業量の配分は `TargetProfile`、GUIの画像は `textures/gui/` で指定します。
