# RPG Mod

Minecraft **26.3 / NeoForge** 向けのRPG系mod。「鍛冶ミニゲーム」と「職業システム（土台）」を実装しています。

## 鍛冶ミニゲーム

**鍛冶台**（鉄インゴット×3・鉄ブロック・石レンガ×2・かまど）を右クリックで開きます。

1. **作るものを選ぶ** — 武器6種（剣・短剣・メイス・ハンマー・魔法の杖・弓）と防具4種（ヘルメット・チェストプレート・レギンス・ブーツ）、**ローブ4種**（フード・ローブ・ズボン・シューズ、インゴット＋糸）× 銅/鉄/金/ダイヤ。素材は通常クラフトと同じ数。**矢**（鉄1・棒1、バニラの矢）も作れて、品質で本数が変わる：普通4／良8／レア16／伝説32
2. **加熱** — 左右に動くバーを止めて初期温度を決める。右ほど高温（威力が高く、バーが遅い）
3. **部位を選ぶ** — 切先・前部・中央・後部・根元をクリック（または 1〜5 キー）
4. **鍛打** — バーを止める（クリック / スペース）。止めた位置で威力が変わる：中央の赤＝強 100% / 黄＝中 75% / 外側の緑＝弱 40% / 枠外＝ミス 0%
   - 叩いた部位に100%、左右の隣に25%
   - 1回叩くごとに温度 −5。温度20以下で強制終了
5. **冷却** — 温度 −15。威力を落として微調整したいときに
6. **仕上げる** — 誤差（不足は×1.0、超過は×1.5で減点）から品質が決まる

| 品質 | オプション数 | 色 |
|---|---|---|
| 普通 | 1 | 灰 |
| 上質 | 2 | 青 |
| 希少 | 3 | 紫 |
| 伝説 | 4 | 金 |

素材が良いほど難しくなります（バーが速く、強・中・弱の幅が狭く、品質判定が厳しい）。難易度：銅×0.85 / 鉄×1.0 / 金×1.1 / ダイヤ×1.2（設定で変更可）。

オプション（重複なし・数値ランダム）
- 武器: 攻撃力、攻撃速度、会心率、会心ダメージ、ボス特効、最大HP（%）、防御力、移動速度、獲得経験値、ノックバック耐性、最大MP（+10〜25）、MP回復（+8〜20%）、魔法攻撃力%・詠唱短縮（杖のみ）
- 防具は2系統（複数部位で重ねがけ可）。自分の系統のオプションは共通のものの2倍出やすい
  - 共通（金属防具・ローブ・盾）: 防御力、防具強度、最大HP、移動速度、ノックバック耐性、耐久値（盾のみ）、獲得経験値、被ダメージ軽減、ボス耐性、会心率（+1〜3%）、会心ダメージ（+3〜8%）（会心は魔法にも効く）
  - **金属防具と盾（近接用）**: 攻撃力（+2〜5%）、攻撃速度（+2〜5%）、ボス特効（+2〜5%）
  - **ローブ（魔職用）**: 魔法攻撃力（+2〜5%）、詠唱短縮（+2〜5%）、最大MP（+5〜12）、MP回復（+4〜10%）
  - 前に作った防具に付いている魔法系オプションはそのまま効く

- 武器の効果はメインハンドに持っている間、防具の効果は装備している間だけ有効
- **会心**：バニラの落下会心とは別枠。会心率＝職業＋鍛冶武器（合計で1回抽選）、倍率＝1.5＋会心ダメージ。近接・矢・スキル・魔法すべてに適用し、落下会心とは掛け算で重複
- 通常クラフトの武器はオプションなし
- ダイヤ → ネザライトへのアップグレードで品質・オプションを引き継ぐ（武器・防具・ローブとも）
- **ローブ**：魔職向けの布の防具。防御力は同じ素材の金属防具（ランク補正込み）の6割（各部位最低1）、防具強度も6割、ノックバック耐性なし。通常クラフト（糸＋インゴット）でも作れる（オプションなし）
- 品質・オプション・製作者はアイテムに保存され、受け渡しやサーバー再起動でも消えない


## 宝石とソケット

装備に「宝石」をはめて追加効果を付けられます。宝石は1つにつき効果1つ。一度はめると取り外せません。

- **ソケット数**：武器・防具・盾すべてに付けられる。銅・鉄・金（とバニラの盾）は1個、ダイヤは2個、ネザライトは3個。ネザライトにアップグレードしても付いている宝石は残る
- **ソケット台**：作業台で「紫水晶の欠片×4＋ダイヤ×1＋鉄インゴット×2」（ADA／AIA／ I ）。左に装備、右に宝石を置いて「装着」。MC経験値を5レベル消費。同じレジェンダリー効果は1つの装備に1つまで
- **効果が働くとき**：その装備を持っている（武器）・着ている（防具）・オフハンドに構えている（盾）間
- **入手**：プレイヤーが倒したモンスターから 0.6%（幸運・ドロップ増加の影響なし）。Lv100を超える敵からは少しずつ上がり、Lv200で 1.5%。ボス（エンダードラゴン・ウィザー・キングスライムなど）は必ず1個落とす
- **レアリティの出やすさ**：通常の敵 コモン80%／レア17%／レジェンダリー3%、ボス コモン50%／レア35%／レジェンダリー15%

| レアリティ | 効果 |
|---|---|
| コモン（緑） | 鍛冶のランダム効果と同じ種類で、数値は鍛冶の約3分の1を**整数に丸めたもの（最低1）**。攻撃力・魔法攻撃力は％ではなく**固定値+1〜3**（Lv100の攻撃力の約1〜3%）、最大HPは%（+1〜2%）。会心率+1〜2%、最大MP+3〜8 など（耐久値以外） |
| レア（青） | 半分はコモンの1.5〜2倍の数値。残り半分は特殊効果：吸血（与ダメの3%回復、5秒に1回／重ねて最大9%）／茨（近接で受けたダメの7%を返す／最大21%）／鈍化（5%で鈍足／最大15%）／毒牙（3%で毒／最大9%）／背水（HP半分以下で与ダメ+5%／最大15%）／追い風（敵を倒すと2秒スピードアップ／最大6秒）／軽業（落下ダメ-17%／最大51%）。同じレア効果は重ねると足し算（上限まで） |
| レジェンダリー（金） | 炎上（攻撃した敵を4秒燃やす）／無限の矢（矢を消費しない）／魔力吸収（攻撃が当たると最大MPの3%回復、5秒に1回）／雷撃（15%で雷、そのヒットの半分の追加ダメージ）／不死鳥（致死ダメージをHP1で耐える、5分に1回）／再生（5秒ごとに最大HPの2%回復）／衝撃波（会心時、周囲3マスの敵にその50%）／氷結（20%で2秒動けなくする）。同じ効果は1つの装備に1つまで、重ねても1つ分 |

- コモン・レアの数値は、鍛冶の効果や他の宝石と足し算で重なる。数値を下げる前に拾った宝石も、自動で新しい基準（3分の1）で効く。会心率などの武器用の効果も、防具にはめれば有効
- 攻撃時の効果は通常攻撃・矢・スキルのどれでも発動する（宝石自身のダメージでは連鎖しない）。ボスには鈍化・氷結が効かない（毒も無効）

## 職業システム（土台）

12職業から、ワールドに初めて入ったときに1つ選びます。あとから「転職の書」で別の職業に変えられます（下の「転職」）。

| 職業 | スキルが使える武器 |
|---|---|
| ファイター | 剣・ハンマー |
| レンジャー | 弓 |
| パラディン | メイス・剣 |
| ウィザード | 魔法の杖 |
| ヒーラー | 魔法の杖・メイス |
| アサシン | 短剣 |
| エンチャンター | 魔法の杖・短剣 |
| ギャンブラー | 短剣・弓 |
| パイレーツ | 銃剣 |
| ランサー | 槍 |
| モンク | ナックル |
| バード | リュート |

- **攻撃側の数値の大きさ**：攻撃力・魔法攻撃力は**バニラの3倍のスケール**（素手3、剣の攻撃力9、矢の攻撃力も3倍）。敵の体力も3倍なので、倒すまでの発数は変わらない。そのぶん数字が細かく調整できる（宝石の攻撃力+1が約1%など）。力のポーション（+9/段）・弱体化（−12/段）も3倍分。敵を倒したときの職業経験値は、体力が3倍になった分を割り戻しているので今までと同じ
- **レベルによる攻撃力の伸び**：攻撃力（魔法職は魔法攻撃力）は**レベルごとに0.6（整数に切り捨てて、ほぼ毎レベル+1）**（Lv100で+59、Lv199で+118。魔法職の物理と、エンチャンターの短剣は0.3）。上級職の分はなし。武器の素材の倍率がこの伸びにも掛かるので、レベルが上がるほど良い武器の差が大きくなる
- **初期装備**：職業を選ぶと、その職業が使える武器をすべて銅で受け取る（メインの武器が先頭：ウィザード・ヒーラーは杖、レンジャーは弓、他は近接武器）。弓を使う職（レンジャー・ギャンブラー）は矢64本も。ほかに鍛冶台・ソケット台・ダンジョンの祭壇を1つずつ（台と祭壇は最初の職業のときだけ。転職で初めてなった職業は武器と矢だけもらえる）
- **成長**：モブを倒すとEXP（最大HPに比例、ボスは3倍・キングスライムは等倍、近くの仲間にも同量）。レベルごとにスキルポイント+1（最大Lv100）。必要EXP＝(15＋2.5×Lv＋Lv²÷8)×序盤補正×2.5。序盤補正はLv1で×3、Lv40で×1に向けてなだらかに下がる（同じくらいの敵で1レベルあたり約6体→Lv20以降は約15体）。Lv100まではこの半分（Lv40までの合計は約9000、Lv100までは約7万）、上級職（Lv101以降）は0.9倍（Lv100→199は、Lv1→100のだいたい4倍の時間）
- **スキルパネル**：職業ごとのハニカム盤面（半径7・169マス）。中央から隣り合うマスを解放。ホイールで拡大縮小、ドラッグで移動
  - ステータスのマス：内側（1〜3周）1pt、中間（4〜5周）は効果1.5倍で2pt、外側（6〜7周）は2倍で3pt
  - スキルは2〜6周目に角度をずらして散らばり（2〜4pt）、必殺技は外周の反対側に2つ（5pt）
  - **スキル強化マス**：スキル・呪文・必殺技のすぐ隣（なるべく外側）に、そのスキル専用の強化マス（スキルの字に「＋」）。最初から使えるスキル（職業の1つ目のスキル・最初の呪文）の強化マスは中央のまわり。そのスキルを覚えていないと取れない。値段はその周のスキルのマスと同じ（内側2pt・中間3pt・外側4pt。ステータスのマスより1pt高い）。上級職のパネルにもある
    - 攻撃スキル：威力+10%・クールタイム−10%
    - 連撃系・連発系（連撃・連射・連突き・乱れ斬り・散弾・マジックボルト・聖光弾・百裂拳・千本槍・天地無双など）：威力+5%・消費MP−15%（何度も当てる・すぐ撃てる技なので小さめ、クールタイム短縮はなし）
    - 回復スキル：回復量+10%・クールタイム−10%
    - 強化・弱体スキル：効果時間+15%・クールタイム−10%（効果時間がないものはクールタイム−10%・消費MP−15%）
    - 必殺技：1マスだけ。威力+10%（連撃系は+5%）か効果時間+15%
  - 攻撃力・魔法攻撃力・防御力はレベルアップとパネルの両方で強く伸びます（敵のレベルに合わせて2倍に強化）
  - **最大体力**はキャラクターレベルで毎レベル同じだけ伸び、Lv199で 近接など500／パラディン（ガーディアン）600／ウィザード・ヒーラー・エンチャンター300（Lv100では約260／310／160。パネルの体力マス +2〜4 は別に加算）。レベルで防御力は伸びない（防御は防具で決まる）
  - 旧データはレベルが「×2−1」に換算され、ポイントは全額返却
- **転職**：「転職の書」を使うと職業選択画面が開き、職業を選んだときに1冊消費（閉じれば消費しない）
  - **レベルはキャラクター共通**：転職してもレベル・EXP・スキルの書のポイントはそのまま。敵のレベルもこのレベルで決まる
  - **熟練度（職業ごと）**：その職業でいる間に得たEXPが貯まる。100%＝Lv1→100に必要なEXPの合計（約7万）。Lv100以上のときは2倍で貯まる。最初の職業はLv100になった瞬間にちょうど100%
  - **スキルパネル**：振り方は職業ごとに保存され、戻ると前の状態のまま。基本職のパネルで、ステータスのマスはいつでも取れるが、スキル・呪文は4周目が熟練度25%、5周目が50%、6〜7周目が75%、必殺技は100%で解放（マスに赤字で必要な%）
  - **上級職**：その基本職の熟練度100%で選べる（書の画面の「上位職」タブ）。解放前は名前・色・スキルが「？？？」で隠れている。熟練度100%なら必ずLv100以上。上級職を選ぶまでは、Lv100を超えた分のポイントは「上位職のポイント」として貯まり、上級職になると全部使える
  - **極めたご褒美**：職業の熟練度が初めて100%になると転職の書を1冊もらえる（全員に告知）。熟練度100%の職業1つにつき最大HP+2%
  - **入手**：モンスターから0.5%（幸運では上がらない）、ダンジョンのボスとエンダードラゴンからは必ず1冊
  - 転職前からのデータは、今の職業の熟練度＝そこまでに得たEXP（Lv100以上なら100%で、上級職のまま）。覚えていたスキルはそのまま
  - 管理者コマンド：`/rpgjob mastery <プレイヤー> <職業> <%>`、`/rpgjob advance <プレイヤー>`（書なしで上級職に）
- **MP**：時間で自然回復（基本1/秒、MPを持つ魔法職・演奏職は+0.5/秒）。ウィザードの**魔力充填**は満腹度6（肉3つ分）を使って最大MPの40%を回復（自分だけ、CT10秒。満腹度が足りないと使えない）。30秒間攻撃も被弾もしないと回復が3倍（HUDに「MP回復 ×3」）。設定 `restRegenDelay`・`restRegenMultiplier`
- **物理職とバード系のMP**：ステータスにMPを持たない職（ファイター・レンジャー・パラディン・アサシン・ギャンブラー・パイレーツ・ランサー・モンクとその上級職、ゴッドハンド・センチネル・シャドウハンター・トレジャーハンター）とバード・マエストロ・スペルシンガーは**最大MP100で固定**（レベルで増えない。装備のMP効果は乗る）。物理職は**通常攻撃を敵に当てるとMPが回復**：前に回復してからの時間×毎秒2（最大1.5秒分＝3）。回復は0.5秒に1回までで、8割以上溜めた攻撃（弓は引き切った矢、パイレーツの銃は全弾）だけが対象なので、連打では回復しない（殴り続ければどの武器でも毎秒約2）。スキル・なぎ払いの巻き込みでは回復しない。物理職の自然回復は戦闘中は3分の1（戦闘外の3倍回復はそのまま）。バード系に攻撃での回復はない
- **必殺技の範囲**：敵を巻き込む範囲・陣の必殺技は範囲が2倍（大地割り・アローレイン・審判・メテオ・時間停止・聖域・大呪詛・ジャックポット・一斉砲撃・竜牙・千本槍・百裂拳・終幕・闘神・魔法剣・極・属性解放・天地の気・百花繚乱・不落の砦・大ルーン陣・艦隊砲撃・天地無双・竜王降臨（燃える地面も）・交響曲・財宝の雨・黄金の大砲）。味方への強化の届く範囲も2倍（大付与・守護の光・不落の城塞・大いなる奇跡・海賊旗・大合奏・大協奏の余韻・神の盾の対象選び）
- **広範囲の持続ダメージの必殺技は効果時間1.5倍**：アローレイン3秒・聖域12秒・千本槍4.5秒（1回に3本ずつ降る）・財宝の雨4.5秒・艦隊砲撃7.5秒・竜王降臨の燃える地面6秒・大ルーン陣22.5秒・交響曲18秒・一斉砲撃12列
- **曲の強化マス**：曲ごとの2マスは「演奏時間+15%」と「消費MP−15%」（スペルシンガーの曲は「演奏時間−15%」：早く終わって余韻が早く始まる）。会心の出来の武器でも同じ強化が付く
- **透明化スキル**：スキルで透明になっている間はモンスターに狙われない（狙っていた敵も見失う）。煙幕・影舞・隠密・闇夜の狩り・影跳び（3秒、新たに透明化）・消失マジック。どれも攻撃すると姿が戻り、また狙われる（毒のダメージでは戻らない）。透明のポーションは対象外
- **バード系の必殺技の強化**：終幕 威力3.0→36.0、交響曲 1音1.0倍（以前0.8）、魔奏・終曲 1音0.8→2.4倍・音符は6つ＋点数4ごとに1つ（最大11。以前は点数の数・最低3つ）、大合奏 周りの敵に毎秒0.8倍のダメージを追加、大協奏 発動時に周りの敵へ10倍のダメージを追加
- **必殺技の見直し**（似ていたものを作り直し）：狂戦士→闘神（次の通常攻撃5回が衝撃斬）、影舞（影2体が通常攻撃をまねる）、神の盾（味方1人を6秒無敵＋全回復）、守護の光（受けたダメージの半分を3秒で回復）、時間遅延→時間停止（3秒、止まっている間のダメージは解除時に+20%）、ほか不落の砦・百花繚乱・極大魔導砲・竜牙・交響曲・大協奏・魔奏・終曲
- **物理職のスキルのMPとクールタイム**：小技・移動 8MP／2.5〜4秒、主力攻撃 15MP／4〜5秒、妨害 15MP／6〜10秒（拘束は効果時間の2倍以上）、大技・範囲 22MP／6〜7.5秒、強化・防御 20MP／15〜25秒（効果時間は以前の2倍）、必殺技 40MP／120秒（無敵・守り系は150秒）が目安。クールタイムが短い分、MPをどう回復するか（殴る・自然回復・ポーション）が選択になる
- **スキル**：Z・X でスキル1・2、C で必殺技（キー設定で変更可）。パネルで覚えたスキルを付け替え可能。職業の武器を持っているときだけ発動、クールタイムとMPあり。必殺技のクールタイムは長め（通常の値の2倍）、蘇生の祈り・大いなる奇跡は5倍。蘇生の祈りは経験値レベル10を消費し、ダウンした味方がいるときだけ使える
- **ウィザード**：杖ごとに呪文4枠。V長押しで円形メニューから選び、右クリックで詠唱
- **画面**：K で職業メニュー（ステータス／スキルパネル／スキル／呪文）。画面右下にレベル・EXP・MP・スキルのクールタイム
- スキルの数値は `JobDefs`、当たり判定と動きは `SkillExecutor`、見た目は `client/fx/`

### スキルのダメージ計算

```
スキルダメージ = 攻撃力 × スキル倍率
```

- **攻撃力**（剣・短剣・メイス・ハンマー・弓の職業）=（素手3 ＋ 武器の攻撃力 ＋ 自身の攻撃力 ＋ 力のポーション）× 武器の素材の倍率 ×（1 ＋ 鍛冶の攻撃力%）。弓は「矢を引き絞った攻撃力 18 ＋ 素材ボーナス」を武器の攻撃力として数えます
- **武器の素材**：武器の種類の攻撃力（剣9・短剣3・メイス12・ハンマー18・杖4.5）に**小さな固定値**を足し、さらに持っている間は**攻撃力全体に倍率**（自分の攻撃力ごと）。銅 +3 ×1.0／鉄 +9 ×1.1／金 +12 ×1.2／ダイヤ +15 ×1.33／ネザライト +18 ×1.45。剣のファイターだと Lv1銅 21／Lv50鉄 62／Lv100ダイヤ 122／Lv199ネザライト 223（Lv199の銅は139）。固定値があるので、序盤に鉄の武器へ替えても手応えがある（Lv1で 21→30）。弓は矢（満タン18）に固定値を足して倍率、杖は魔法攻撃力「9＋固定値」で倍率も同じ
- **重量武器補正**：メイスとハンマーは通常攻撃（スキル以外）のダメージ全体に倍率がかかる（メイス×1.25、ハンマー×1.6。`rpgmod-jobs.toml` の `maceAttackMultiplier` / `hammerAttackMultiplier`）。スキルのダメージには影響しない。Lv100・ダイヤの通常攻撃の秒間ダメージは剣を100としてメイス約94%・ハンマー約80%
- **弓補正**：弓・クロスボウで撃つ通常の矢のダメージ ×1.4（`bowAttackMultiplier`）。引き絞りに0.8秒かかり（剣は0.5秒に1振り）矢も使うため、通常攻撃だけの秒間火力は剣の約97%。**ボスには ×1.0**（`bowBossAttackMultiplier`。安全な距離から撃てるぶん、剣の約70%）。スキルの矢には掛からない
- **軽量武器補正**：短剣とナックルは振りが速く（0.5秒未満）、以前は2回に1回が敵の無敵時間で消えていた。今は満タンの振りは全部当たる代わりに、通常攻撃のダメージ ×0.5（`daggerAttackMultiplier` / `knuckleAttackMultiplier`）。秒間の通常攻撃ダメージは以前と同じで、攻撃速度アップ（加速・号令）がそのまま効くようになった
- **魔法攻撃力**（ウィザード・ヒーラー・エンチャンターのスキルと呪文）=（3 ＋ 杖の魔法攻撃力 ＋ 自身の魔法攻撃力 ＋ 宝石の魔法攻撃力）× 杖の素材の倍率 ×（1 ＋ 鍛冶の魔法攻撃力%）。杖：銅12／鉄18／金21／ダイヤ24／ネザライト27、倍率は武器と同じ
- **自身の攻撃力・魔法攻撃力**は職業の初期値＋レベルアップ（0.6/レベル）＋スキルパネル（1マス +0.6〜1.2。武器の倍率も掛かる）で増えます
- **スキル倍率**：攻撃スキルは表の倍率の**0.75倍**で計算（回復・バフと、ウィザードの通常攻撃にあたるマジックボルト、ガーディアンの報復は対象外）。強撃は3.0→2.25で、同じレベルの敵の体力の4割ほど（スキル1発＋通常攻撃2〜3発で倒せる）。ヒール（回復）90% など。職業画面のスキル説明に「威力 攻撃力×300%（今 21.0）」と表示
- **個別の調整**：ロシアンルーレット 倍率10→6・CT2→3秒、審判 2.5→6.0、大地割り 5.0→8.0、サンダー 3.3→4.5、重力 2.4→3.6（いずれも0.75倍の前の値）
- **ウィザードの大技**：サンダー・フレイムバースト・重力はクールタイム1.5倍・威力1.8倍（火力+20%、一発が重く、MP効率も良い）。サンダー CT10→15秒・4.5→8.1、フレイムバースト CT6→9秒・2.1→3.78、重力 CT12→18秒・3.6→6.48。融合魔法での価値も同じ割合で上げた
- そのあと会心・ボス特効・敵の防具（魔法も同じく防具で減る）が掛かります。スキル威力と防具貫通は廃止（貫通の付いた鍛冶装備・宝石は同じ数値の攻撃力%として働く）
- **ヒット後の無敵時間はプレイヤーごと**：バニラでは敵は攻撃を受けると0.5秒間、それより大きいダメージの差分しか受けない（誰の攻撃でも共通）。スキルはもともとこれを無視するが、スキルが当たるたびに無敵時間が始まり直すため、自分や味方のスキルの直後の通常攻撃（剣を振る・弓の矢）はほとんど消えていた。プレイヤー→敵の通常攻撃・爆発などは **プレイヤーごと・種類ごと** の0.5秒に変更（自分の通常攻撃どうしは「武器の振りの9割」まで短くした間隔で、満タンの振りは必ず当たる。ナイトブレードの左手の短剣は別枠）。スキル・毒は今までどおり無敵時間なし。プレイヤー同士・モンスターの攻撃はバニラのまま
- **弓の通常射撃**にも自身の攻撃力（レベル・パネル・力のポーション・攻撃力アップなど。弱体化はマイナス）が乗ります。引き絞り具合に比例し、満タンで「ステータス画面の攻撃力」と同じダメージになります（そのあと会心）
- **攻撃力アップ**（スキル専用のバフ）：攻撃力 +20%（II は +40%）。雄叫び・付与・ギャンブル（コイン・ダイス・オールイン）の「全体強化」・大ルーン陣がI、鷹の目・大付与・血の狂乱がII。以前はバニラの「力」（+9/レベル）だったもの。弓は矢の分にも掛かる。バニラの力のポーションはそのまま
- **エンチャンターのバフ**（付与・加速20秒・炎の付与・大付与30秒）の効果時間は魔法攻撃力で増減：表記の時間 ×（魔法攻撃力 ÷ 10）、0.5〜3倍。スキル説明に今の効果時間を表示。設定 `enchanterBuffReferenceAttack` / `enchanterBuffMinMultiplier` / `enchanterBuffMaxMultiplier`
- スキル消費MP：ファイター・レンジャー・パラディン・アサシン・ギャンブラーは一度半分にしたあと、全職業×1.4（例：強撃10.5、メテオ112、ヒール21）
- ウィザード以外の職業の攻撃スキル倍率は2倍に調整済み（回復・MP回復・移動系は据え置き。聖なる波・カード投げ・ギャンブルの回復/MP/自爆分は倍率が上がっても以前と同じ量）
- ウィザードの攻撃呪文（マジックボルト以外）は倍率1.5倍、メテオは3倍（9.0）に調整済み。マジックボルトは威力そのままで、クールタイム0.3秒・消費MP5（通常攻撃のように撃ち続けられる）

### スキルの演出と範囲

全72スキルに専用の演出があります。自作の発光パーティクル（加算合成）で、魔法陣・斬撃の弧・衝撃波・氷片・羽・コインなどを描きます。サーバーは「何が起きたか」だけを送り、パーティクルはクライアントで時間差アニメーションするので、マルチでも通信は軽いです。ビデオ設定の「パーティクル」を減らすと演出の量も減ります。

| 種類 | 例 | 当たり方 |
|---|---|---|
| 扇形 | 強撃（半径4.5・左右65°）、盾打ち（4）、毒刃（4） | 前方の扇形に一度 |
| 周囲 | 旋風斬（4.5・2回ヒット）、フロストノヴァ（6） | 広がる波が届いた順にヒット |
| 衝撃波 | 大地割り（7） | 地面を走る衝撃波が通過した敵に |
| 狙い撃ち | マジックボルト（28・追尾）、裁きの一撃（8）、暗殺（12） | 照準に近い敵を自動で狙う |
| 着弾点 | メテオ（36先・半径11）、サンダー（28・連鎖3体）、アローレイン（32・半径10）、罠（14） | 見ている地面に予兆→時間差で着弾 |
| 設置 | 聖域（6・8秒）、罠（4秒） | その場に残り続ける |
| 移動 | ブリンク（10）、影歩き（敵の背後へ）、突進 | 壁や地面に埋まらない位置へ |

- 大技（メテオ・大地割り・審判など）は近くのプレイヤーの画面が揺れます
- 杖の詠唱中は足元に魔法陣が広がり、詠唱完了で光ります
- 会心とレベルアップにも専用の演出
- **スキルの付け替え**：スロット（スキル1・2・必殺技、杖の魔法）に新しく入れたスキルは**10秒間使えない**（もともと残っていたクールダウンの方が長ければそちら）。戦闘中に付け替えて次々使うのを防ぐため。スロット1と2の入れ替えだけなら掛からない（設定 `skillSwapCooldown`）
- **効果時間はレベルで伸びる**：効果時間のあるスキル・魔法は、レベルに応じて最大+50%（Lv100）まで長くなる。必殺技と、魔法攻撃力で伸びるエンチャンターのバフは対象外（設定 `skillDurationBonusAtMax`）
- 消費MPはすべて整数
- **幸運**（ギャンブラーが伸びる）：幸運1につき5%（最大50%）の確率で、ギャンブルを**もう1回振って良い方を取る**。対象はコイントス・ダイス・オールイン・ジャックポット（大当たり＞強化＞回復＞MP＞呪い＞自爆の順で良い方）、ルーレットの出目（大きい方）、ラッキーショットの当たり、ロシアンルーレットの発砲、カード投げのスペード。ステータス画面に「振り直し○%」と表示（設定 `luckRerollPerPoint`）
- **盾**：ガードで防げるのはダメージの一部だけ（残りは受ける）。バニラの盾20%、鍛冶の盾は銅40%／鉄50%／ダイヤ60%／ネザライト60%（パラディンはどの盾でも+20%）。
- **装備は壊れない**：鍛冶で作れる武器（剣・短剣・メイス・ハンマー・杖・弓）と防具（頭・胴・脚・足）は、銅〜ネザライトまで耐久が減らず壊れない（作業台で作ったもの・拾ったものも同じ）。革・チェーンの防具、つるはし・斧などの道具は今まで通り
- **盾の耐久**：盾は壊れない。ガードで耐久が0になると「壊れた」状態になり、30秒（ネザライトは15秒）ガードできない（斧で割られたときと同じクールダウン表示）。時間が経つと耐久満タンで復活する。インベントリやチェストに入れていても時間で戻る（次に手に取ったとき）。盾を構えている間はスキル・魔法を使えない
- **盾の作り方**：鍛冶台で「バニラの盾1＋インゴット（ダイヤ）3」から銅・鉄・ダイヤの盾を鍛える（防具と同じランダム効果。オフハンドで効く）。作業台でも同じ材料で効果なしの盾が作れる。ネザライトは鍛冶型（ネザライトアップグレード）でダイヤの盾から。見た目は素材の色の盾
- **上級職**：Lv100で自動的に上級職へ（ファイター→バーサーカー、パラディン→ガーディアン、レンジャー→シャープシューター、ウィザード→スペルマスター、エンチャンター→ルーンマスター、ギャンブラー→ジョーカー、アサシン→ナイトブレード、ヒーラー→ビショップ）。上級Lv1〜100（全体Lv100〜199、ステータスはそのまま伸び続け、上級職ごとの伸びも上乗せ）。上級Lv1ごとに上級ポイント+1、上級パネルでだけ使える。スキルパネル画面のボタンで通常パネル／上級パネルをいつでも切り替え（どちらも別々にリセット可）。スキル枠が1つ増えて3つ＋必殺技（スキル3は B キー）。敵のレベルは全体Lvに合わせて上がる（上級Lv50なら敵は約Lv150）。
- **上級職のスキル**（上級パネルで習得。スキル画面・呪文画面は「表示中：〜」ボタンで基本職／上級職の一覧を切替）
  - バーサーカー：ファイターから受け継ぐ雄叫びの攻撃力アップは**自分だけ**（パーティには掛からない）。血の狂乱（HP15%を払って攻撃力アップII・攻撃速度）、断頭（HP半分以下の敵に2倍）、怒涛の三連旋風、捨て身の突進（4秒被ダメ+30%）、威圧の咆哮（敵の攻撃・速度ダウン＋自分の会心率+25%）／必殺：修羅（与ダメ+40%、HPが減るほど上がり最大+150%・通常攻撃の与ダメの15%回復。スキルでは回復しない）。**血の代償**：MPが足りないときはHPで払ってスキルを使える（足りないMP1につき最大HPの0.5%。一度払うと6秒は払えない。HPが1残らないなら使えない）
  - ガーディアン：鉄壁（被ダメ半分・ノックバック無効）、挑発の盾（敵を引きつけ防御+16）、かばう（周りの味方の被ダメの70%を肩代わり）、シールドウォール（飛び道具を止める光の壁）、反撃（近接攻撃してきた敵に反撃ダメージ）／必殺：不落の城塞（味方に耐性III、自分はHPが1未満にならない）
  - シャープシューター：狙撃（防御無視・射程64）、速射（8連射）、弱点看破（被ダメ+60%）、跳弾（最大5体）、ローリング（次の弓矢2.5倍）／必殺：デッドアイ（見えている敵全員へ追尾弾）
  - スペルマスター：二重詠唱（次の2回の呪文がもう一度発動）、魔力暴走（魔法攻撃1.5倍・呪文MP1.5倍）、マナの泉、位相転移（瞬間移動＋1.5秒無敵）、魔封陣（被ダメ+30%の陣）／必殺：極大魔導砲（3秒間、向いている方向に極太の光線を撃ち続ける）／呪文8つ（詠唱長め）：獄炎、絶対零度、雷霆、岩槍、聖槍、暗黒球、竜巻、星屑
  - ルーンマスター：大地のルーン、守護のルーン、疾風のルーン、暗視の加護（暗視＋水中呼吸）、羽のルーン（落下ダメージ無効）／必殺：大ルーン陣
  - ジョーカー：すり替え（敵と位置交換）、分身（モンスターを引きつけて爆発）、いかさま（次の賭けが必ず最高の結果）、トランプの嵐、消失マジック（敵の背後へ・モンスターから見えなくなり次の一撃2倍）／必殺：ワイルドカード（全職業の必殺技からランダム）

### パイレーツ・ランサー・モンク・バード

- **パイレーツ（銃剣・中衛）**：銃剣を**右クリックで発射**（攻撃力×90%、射程32、0.5秒に1発）。**6発撃つと自動で装填**（2秒。しゃがみ＋右クリックで早めに装填）。照準の下に残弾。スキル：突撃射（踏み込んで突き＋至近射撃、1発装填）・早撃ち（残弾を全部連射、最低3発）・大砲設置（横に大砲を置き10秒間、近くの敵を自動砲撃。範囲ダメージ）・火薬樽（2秒後に爆発。撃ち抜くとその場で1.5倍の誘爆。地形は壊さない）・かぎ縄（敵を引き寄せる／大きい敵には自分が飛ぶ／敵がいなければ狙った場所へ）・ラム酒（HP15%回復＋攻撃速度）・必殺技：一斉砲撃（背後から頭上を越えて砲弾が飛び、狙った範囲を手前から奥へ1列3発ずつ絨毯爆撃）・海賊旗（旗の周りの味方の与ダメージ+20%、15秒。その間は大砲の連射2倍、弾切れなし）
- **ランサー（槍・中衛）**：武器は**バニラの槍**（見た目・突き・右クリック長押しの突撃もバニラと同じ。**オフハンドに盾を持つと、右クリックは盾のガードになる**（槍の突撃の代わり。盾が使えないあいだは突撃）。届く距離4.5、近くの敵にも当たる）。**槍の先（2.5ブロック以上離れた敵）で当てると+25%**。スキル：突進（だんだん加速しながら突っ込み、当たった敵を最大3体まで槍に乗せて運ぶ。最後に速さに応じて投げ飛ばす。壁にぶつけると大ダメージ＋気絶）・槍投げ（直線上の敵を貫いて戻ってくる。戻りも半分のダメージ）・薙ぎ払い（前方の広い扇形、吹き飛ばし）・跳躍突き（槍を地面に突いて棒高跳びで狙った地点へ。着地点を突き、そこから前方一直線に衝撃波が走って敵を打ち上げる）・迎撃の構え（2秒、受けるダメージ半分、近づいた敵・殴ってきた敵に自動で反撃）・連突き（正面に5回）・必殺技：竜牙（3秒間、槍を振り回しながら前進。敵を巻き込んで運び、最後に打ち上げる）・千本槍（3秒間槍を降らせる。槍は地面に刺さって残り、最後に一斉に炸裂。近くに刺さった本数ぶん追加ダメージ、最大4本）。跳ぶスキルの着地で落下ダメージなし
- **槍の職（ランサー・ドラグーン・センチネル）のスキル威力は全体に+25%**（通常攻撃のリーチが長いぶん、それ以外は据え置き）
- **モンク（ナックル・近接）**：**気（0〜5）**：**6回分で気1つ**（ナックルの通常攻撃1回で1/6 ― 振りが全部当たるようになり回数が倍なので、時間あたりは以前と同じ。スキルで気が溜まるものは表記の2/3：連撃は当たるたび2/3、受け流し・旋風脚は最大4/3など。瞑想の最後の満タンはそのまま）。照準の下に表示（溜まりかけの気は下から満ちていく）。8秒戦わないと1秒に1ずつ減る（溜まりかけの分が先に消える）。**ナックルで右クリック長押しで気弾をチャージ**：1〜3チャージ目は0.6秒ごと、4チャージ目からは1秒ごとに1チャージ（気1つ）、今ある気の数まで（5チャージで3.8秒）。チャージが溜まるたびに音が上がっていき、気を使い切ると鐘の音。離すと撃つ（1チャージ目の前に離すと何も起きず気も減らない）。威力は攻撃力×120%×チャージ数（1=×1.2、3=×3.6、5=×6.0、7=×8.4）。チャージ数だけ弾が大きく、強く吹き飛ばす。射程20、狙った敵に少し曲がって飛ぶ。チャージ中は歩く速さ45%、使われる気が照準の下で白くなる。チャンピオン・ゴッドハンドも同じ。扉やチェスト・村人などに向けたときと、スニーク中は普通の右クリック。スキル：連撃（3連打、当たるたび気+1）・発勁（気を全部使い、1つにつき威力+120%）・受け流し（1.2秒、次の近接攻撃を無効にして反撃、気+2）・旋風脚（周りを蹴り飛ばし、当たった数だけ気、最大2）・瞑想（3秒動けない、毎秒最大HPの8%回復、終わったときに気が満タン。瞑想中は気は溜まらない）・縮地（狙った敵の背後へ瞬間移動して背中を打つ。背後からなので1.3倍、残像が残る、気+1）・必殺技：百裂拳（3秒間の連打＋最後に強打）・金剛（6秒、受けるダメージ−80%、吹き飛ばされない、攻撃が当たるたび気）
- **バード（リュート・支援）**：**曲はウィザードの呪文と同じくリュートにセット**（4枠、ホイールで選ぶ）し、スキル「**演奏**」で選んでいる曲を演奏する（どの曲も12秒。MPとクールダウンは曲ごと）。画面下に**音符のレーン**が出て、音符が右から流れてきて左の線に重なったときに**左クリック**：±2ティックで**パーフェクト**（+2）、±4で**グッド**（+1）、それ以外・見逃しは**ミス**（−3）。この点数（0〜20）で歌の強さ60%〜120%、届く範囲6〜10ブロック。16点以上で歌が終わると**アンコール**（6秒延長、1回。スペルシンガーの曲にはない）。演奏時間はレベルでは伸びない（12秒。曲の強化マスで変わる）。演奏中は移動が遅くなり、剣などの通常攻撃はできない（左クリックは演奏用）。**リュートを右クリックで音波**（魔法攻撃力×80%、1発1MP、演奏中も撃てる）。曲：戦いの歌（与ダメージ+9〜18%）・癒しの歌（毎秒最大HPの1.2〜2.4%回復）・守りの歌（受けるダメージ−9〜18%）・風の歌（移動+12〜24%・攻撃速度+9〜18%）・不協和音（周りの敵に毎秒ダメージ＋防御ダウン）・子守唄（周りの敵の動きと攻撃が鈍る）・狂詩曲（会心率+9〜18%）・凱歌（スキルのクールダウンが早く回る）・葬送曲（周りの敵から毎秒HPを吸い、その3割で味方を回復。1人あたり毎秒最大40）・豊穣の歌（周りの味方の満腹度と隠し満腹度を毎秒0.3ずつ×曲の強さ0.6〜1.2で回復。1曲で各3〜4、完璧に弾いてアンコールまで行くと各5〜6。ヒーラーの恵みの糧（4＋4）より少し多い。※追加でバードのスキル盤の配置が変わるため、バードのポイントは返却される）。スキル：演奏・衝撃音（前方に音の衝撃波、吹き飛ばし。演奏中も使える）・鼓舞（演奏の点数+6、味方の攻撃力を5秒アップ）・必殺技：大合奏（10秒、4つの歌を最大の強さで同時に）・終幕（演奏を終え、点数に応じた衝撃波）。エンチャンターとの違い：自分の周りにいる間ずっと効く・上手に弾くほど強い・同時に1曲

### 複合職

- **ゴッドハンド**（ヒーラー×モンク・ナックル）：気はモンクと同じ（ナックルで溜まる）。右クリックの気弾は当たるとチャージ数×最大HPの2%回復。練気・治癒の掌（自分と周りを回復）・硬気功（気を使って被ダメージ減）・発勁・癒（与ダメージの3割回復）・流水歩（近くの敵3体の間をジグザグに縫って打つ。触れるたびにHP4%回復）・必殺技：天地の気（大回復＋衝撃波）／百花繚乱（8秒の花の陣。中から攻撃を当てるたびに陣の中の味方が回復、終わりに花が散ってダメージ）
- **センチネル**（パラディン×ランサー・槍＋オフハンドに盾）：右クリックで盾を構えられる。槍の先の+25%もある。守突・盾突撃（盾で最大5体を押し込みながら突進。壁にぶつけると2.5秒気絶＋大ダメージ、壁がなければ最後に押し飛ばす）・不動の構え（被ダメージ−40%）・槍衾（その場に槍の陣）・反撃の槍（3秒間盾で構え、受けるダメージ60%減。防いだ分を4倍で溜め、構えの後6秒以内の次の近接攻撃に上乗せ）・挑発・必殺技：不落の砦（10秒間、周りの味方の被ダメージ−30%。防いだ分を溜めて終わりに槍の衝撃で放つ）／聖槍（前方一直線）。初期装備に盾も付く
- **スペルシンガー**（エンチャンター×バード・リュート）：演奏はバードと同じ（リュートに曲をセットして「演奏」、音符のレーン）。**アンコールはない。曲の効果はバードより控えめだが、曲が終わった後も、終わったときの点数に応じて長く残る（余韻：1点につき5秒、最大100秒。MP回復と雷は毎秒続く。魔力の和音だけは余韻が最大30秒で、毎秒の回復は最大MPの0.36〜0.72%）。切れたらかけ直す使い方**。曲：炎の旋律（味方の攻撃が燃えて威力アップ）・加速の調べ・魔力の和音（味方のMP回復）・封印の旋律（敵の守りを崩す）・雷鳴の調べ（毎秒敵1体に雷）・守護の旋律（味方に衝撃吸収＝HPバーの黄色、最大HPの15〜30%。削られた分は戻らず、割れると4秒間は付かない。演奏が終わったとき近くにいた味方は、残っている分が200秒続く）・吸魔の調べ（味方の攻撃が当たるたびにMPが少し回復）。スキル：演奏・魔音符（追いかける音符を3つ）・共鳴（味方の良い効果を5秒延長）・必殺技：大協奏（セットした全曲の余韻を最高点で100秒）／魔奏・終曲（点数の数だけ追尾する音符、当たった敵は3秒間攻撃できない）
- **シャドウハンター**（アサシン×レンジャー・弓＋短剣）：急所狙い（体力半分以下の敵に2倍）・隠密（姿を消し、次の一撃は必ず会心で+60%）・影縫いの矢・罠設置・影跳び・扇投げ・必殺技：闇夜の狩り（10秒、周りの敵すべてを獲物に＝自分からのダメージ+50%）／影の雨（狙った1体に影の矢を集中して縫い止める。命中ごとに近くの敵へ跳ねて半分のダメージ＋縫い止め）
- **トレジャーハンター**（ギャンブラー×パイレーツ・銃剣）：銃剣の銃も使える。ギャンブル砲（爆発・氷・毒・金貨・不発・大当たりのどれか）・金貨散弾・宝箱の罠（敵を引き寄せて噛みつく）・盗む（宝石ではなくエメラルドや金塊など、1体1回）・幸運の羅針盤（120秒、倒した敵が宝を落とす）・ダブルダウン（12秒、ダメージが毎回2倍か半分）・必殺技：財宝の雨（金貨の雨。一部は地面に残り、拾うとゴールドラッシュ＝与ダメージ+5%、最大5重）／黄金の大砲

- 管理者コマンド：`/rpgjob info|reset|set|level|exp <プレイヤー> ...`
- 敵を倒した経験値は、倒した人から**70ブロック以内**にいるプレイヤー全員がまるごと受け取る（同じディメンションのみ）
- 設定：`config/rpgmod-jobs.toml`（`maxJobLevel` 最大レベル、EXP倍率、共有範囲 `expShareRadius` など）

## 敵の強化

### 敵レベル

モンスターは出現したときにレベルが決まり、強くなります（一度決まったレベルはそのまま保存）。

- **標準**：オンラインのプレイヤーのうち一番高い職業レベル ＋0〜3（例：最高Lv31なら Lv31〜34）。エンダードラゴンはLv200固定
- 設定 `levelsFromPlayers = false` にすると、場所で決める方式になります：

| 場所 | レベル | 決まり方 |
|---|---|---|
| オーバーワールド | Lv1〜40 | 初期スポーン地点から100ブロックごとに+1。y=0より深い地下は最大+5 |
| ネザー | Lv35〜60 | ネザーでの距離×8（オーバーワールド換算）250ブロックごとに+1 |
| エンド | Lv70〜85 | 中央の島はLv70、外側の島ほど高い（800ブロック先から400ブロックごとに+1） |
| エンダードラゴン | Lv200固定 | |

- すべての敵対モブの移動速度は1.5倍（`monsterSpeedMultiplier`）。ドラゴンは体力3600（サーバーの人数で増える。下の「エンダードラゴン」参照）

レベルごとの強さ：

| Lv | 体力 | 攻撃力 | 爆発 |
|---|---|---|---|
| 1 | ×3.00 | ×1.00 | ×1.00 |
| 20 | ×7.07 | ×3.02 | ×1.51 |
| 40 | ×11.51 | ×5.20 | ×2.05 |
| 60 | ×16.12 | ×7.44 | ×2.61 |
| 80 | ×20.90 | ×9.73 | ×3.18 |
| 100 | ×25.85 | ×12.08 | ×3.77 |
| 150 | ×38.95 | ×18.20 | ×5.30 |
| 200 | ×53.11 | ×24.67 | ×6.92 |

- 体力 ×3×(1＋0.07(Lv−1)＋0.00007(Lv−1)²)（攻撃側と同じく3倍スケール。バニラの最大体力の上限1024は外してある）、攻撃 ×(1＋0.105(Lv−1)＋0.00007(Lv−1)²)。プレイヤーの体力（Lv199で500）に合わせた伸びで、どのレベルでも「同じレベルの敵は近接で5〜6発、レベル相応の防具なら敵の攻撃を10発ほど耐える」くらいになるよう決めてあります。パネルの攻撃力にある程度振った人がちょうどこの発数（振っていなければ1発ほど多い）（設定 `healthGrowthLinear/Square`・`damageGrowthLinear/Square`）
- 攻撃力は近接・矢・火の玉などすべてに掛かります。クリーパーの爆発も他の攻撃と同じだけ伸びます（TNTなど他の爆発は伸びを抑えてあります）
- 目安（難易度ノーマル）：Lv55のエンダーマンの一撃は素で約48、Lv110だと約93（ネザライト一式で約27、体力約290に対して）
- 職業の経験値は敵の最大体力に比例するので、遠くの強い敵ほど多くもらえます。バニラの経験値オーブも +2%/Lv
- 頭上に「Lv・名前・体力バー」（照準を合わせた敵と最近攻撃した敵は名前と数値つき）。受けたダメージは白い帯が遅れて減ります
- ダメージ数字：通常＝白、会心＝金「!」付き、魔法＝紫、炎＝橙、毒＝緑、回復＝緑「+」、プレイヤーの被ダメージ＝赤

### ボスのユニーク武器

ダンジョンのボスを倒すと、報酬を受け取る人（攻撃した人・近くにいた人）それぞれに**25%**で、そのボスのユニーク武器が1つ手に入る。自分の職業が使う武器種がそのボスにあればその中から、なければボスの武器からランダム。

- **強さはボスのレベルで決まる**：Lv100でダイヤ製、Lv180でネザライト製と同じくらい、それ以上はさらに強くなる（最大Lv300）。品質は並40%・上質30%・希少20%・伝説10%で、鍛冶と同じようにオプションが付く（会心の出来も20%）
- **ソケットは1〜3個でランダム**（手に入ったときに決まる）。鍛冶台でネザライトにアップグレードはできない
- クリエイティブのタブに、10種それぞれのLv100とLv180（伝説）がある
- 説明文に「★ ユニーク Lv〇〇（ボス名）」と固有効果が出る。固有効果は強すぎないよう、ほとんどに短いクールタイムがある

| ボス | 武器 | 固有効果 |
|---|---|---|
| キングスライム | スライムの大剣（剣・大きい） | 攻撃すると周りの敵にスライムが飛び散る（30%のダメージ＋鈍足、1.5秒に1回） |
| キングスライム | 弾む大槌（ハンマー） | 殴った敵が高く跳ね、着地で周りの敵に40%のダメージ（4秒に1回） |
| ゴーレム | 岩砕きのメイス | 4回目の攻撃ごとに地面を割り、周りの敵に60%のダメージ |
| ゴーレム | 岩王の槍 | モンスターに攻撃されると岩の皮膚（最大HPの12%の吸収、8秒。20秒に1回） |
| ゴーレム | 岩拳（拳） | 10回目の攻撃ごとに敵を1.5秒気絶（6秒に1回） |
| 亡者の王 | 亡王の杖 | 敵を倒すと最大MPの4%を回復（4秒に1回） |
| 亡者の王 | 亡者のリュート | 倒した敵の魂が近くの敵に飛び、魔法攻撃力の1.5倍（2秒に1回） |
| 蜘蛛の女王 | 女王の毒牙（短剣） | 攻撃で毒。同じ敵に続けて3回で糸で1.5秒縛る（6秒に1回） |
| 蜘蛛の女王 | 女王の糸弓（弓） | 矢が当たった敵を糸で1.5秒縛る（5秒に1回） |
| 蜘蛛の女王 | 毒散の銃剣 | 銃剣と銃弾が毒を与える |

### 会心の出来（鍛冶）

武器を鍛えると、品質（並・上質・希少・伝説）に関係なく**20%で「会心の出来」**になる（防具・ローブ・盾は対象外）。その武器を使う職業（基本職・ハイブリッド職と、その上級職）のスキル・呪文・必殺技から1つが選ばれ、スキル盤の強化マス1つ分の1〜1.5倍の強化が付く（例：威力+10〜15%、クールタイム−10〜15%、消費MP−15〜22%、効果時間+15〜22%）。**メインハンドに持っている間だけ**効き、スキル盤の強化と重なる。説明文に「★ 会心の出来」と強化内容が出る。**上級職のスキルが選ばれるのは製作者がLv100以上のときだけ**（ユニーク武器はボスのレベル）。まだ開放していない職業（なったことのない基本職・ハイブリッド職、熟練度を満たしていない上級職）のスキルは「？？？」と表示され、開放すると中身が見える

### 製作品の名前（おまけ）

鍛えた装備には、ランダムな2つの言葉を合わせた名前が付く（例：「きらきら光るダイヤの剣」「めらめら唸る鉄の槍」）。言葉は24×24通り、各プレイヤーの言語で表示。金床で名前を付ければそちらが優先

### エリート個体

普通の敵の8%（設定 `eliteChance`）が**特性を持ったエリート**として出現します。特性はLv59までは1つ、Lv60〜129で2つ、Lv130以上で3つ。ボス・ボスの手下・クリーパー・シュルカー・ウォーデン・エルダーガーディアンはエリートになりません。

- 名前の前に【特性】が付き、遠くからでも常に名前が表示される。体が15%大きく、足元に特性の色の紋章、体の周りに特性ごとのオーラ
- 体力×2.5、攻撃×1.25。宝石が3倍、回復薬が2倍落ちやすい（倒すまでが長い分、職業経験値も体力に比例して多い）
- **初見殺しになる特性は入れていない**：見て分かり、対処できるものだけ（自爆・ダメージ反射・瞬間移動・透明化・即死・大量召喚・毒の床などはなし）

| 特性 | 効果 | 対処 |
|---|---|---|
| 鉄壁 | 受けるダメージ−35% | 時間をかける・強いスキルで |
| 俊敏 | 移動速度+30% | 足止め・距離に注意 |
| 剛力 | 攻撃+40%、移動−10% | 遅いので距離を取る |
| 再生 | 3秒攻撃されないと毎秒最大HPの3%回復 | 攻撃を途切れさせない |
| 吸血 | 与えたダメージの25%回復（赤い線が出る） | 被弾を減らす |
| 分裂 | 倒すと小さな2体に分かれる（体力3割、ドロップなし） | 範囲攻撃で |
| 号令 | 周り8ブロックの敵の攻撃+20%（金の線でつながる、頭上に紋章） | 先に倒す |
| 結界 | 魔法ダメージ半減 | 物理で |
| 不屈 | 吹き飛ばない | 押し返しに頼らない |
| 炎纏い | 攻撃で3秒燃やす、炎が効かない | 被弾を減らす・消火 |
| 冷気 | 攻撃で1.5秒鈍足 | 被弾を減らす |
| 守護 | 10秒ごとに足元に青い輪（1.5秒の予兆）→周り8ブロックの敵に最大HPの15%の衝撃吸収 | 予兆中に倒す・離れる |

### 亡者の冒険者（洞窟限定）
オーバーワールドの洞窟（y40未満・空が見えない場所）で自然湧きするモンスターの約25%が、かつての冒険者のなれの果て「亡者の冒険者」に置き換わる（`revenantChance`、0で無効）。洞窟のモンスター上限は普段どおりなので、全体の数は増えない。

- **湧き方**：74%は1体（戦士・魔導士・弓兵・盗賊のどれか）。18%は攻撃役＋神官の2体。8%は戦士・魔導士・弓兵か盗賊・神官の4人パーティ。神官は単独では出ない。
- **強さ**：ゾンビと同じ攻撃力のまま、体力は1.5倍（30）。武器はレベルに応じた職業の武器を持つ（ほかのモンスターの装備と同じく、威力は一部だけ反映）。ゾンビ化・子供・建築や掘削はなし。
- **索敵範囲**：64ブロック（ゾンビなどほかの敵と同じ）
- **技はすべて予兆つき**：
  - 戦士：突進（地面に赤い直線。0.8秒後に突進、攻撃力×1.3）、薙ぎ払い（扇形の予兆から0.7秒後、×1.5）
  - 魔導士：6〜14ブロックの距離を保ち、火球（足元に詠唱陣、着弾点に赤い円。円が満ちたころに着弾、×1.3＋着火）
  - 弓兵：普段は弓で射撃。時々レーザーサイトで1.2秒狙ってから強射（×1.6）
  - 神官：プレイヤーから距離をとり、仲間の後ろにつく。仲間が傷つくと1秒の詠唱のあと、10ブロック内の仲間を最大体力の15%回復
  - 盗賊：移動速度+25%。短い直線の予兆から0.5秒後にダッシュ斬り（×1.2）
- **ドロップ**：腐肉に加え、プレイヤーが倒すと職業ごとの品（戦士：鉄、魔導士：ラピスラズリ、弓兵：矢、神官：金塊、盗賊：エメラルドか金塊）。

### ダンジョン（迷宮の祭壇）
**迷宮の祭壇**に捧げ物をすると、専用の次元にダンジョンが開きます。祭壇を右クリックで入場。クリアされるまで開いたままなので、後から仲間が合流できます。

- **祭壇**：作業台で「エンダーアイ・金インゴット×2・模様入りの深層岩・黒曜石×3」（ E ／GCG／OOO）。ダンジョンが開いている間は光り、壊せません
- **捧げ物**
  - **迷宮の鍵**：4部屋のダンジョン。敵のレベルは中にいる一番レベルの高いプレイヤーに合わせる。クラフトはできない。エリート（12%）と亡者の冒険者（4%）が落とし、最終部屋の宝箱からも出る（35%）
  - **封印の鍵 Lv○○**：敵のレベルが固定のダンジョン。最終部屋の宝箱からそのダンジョンのレベルで出る（20%）
  - **ボスの捧げ物**：入口からすぐボスの闘技場。そのボスと戦える
    - **スライムの王冠** → キングスライム／**ゴーレムの核** → ゴーレム／**魂の器** → 亡者の王／**女王の繭** → 蜘蛛の女王
    - クラフトはできない。最終部屋の宝箱から20%で4つのうちどれか1つが出る
- **部屋**：入口ホール → 3部屋（27×27）→ 最終部屋（41×41、闘技場は51×51）。部屋に踏み込むと戦闘開始、**3ウェーブ**を全滅させるまで先の扉（鉄格子）は開かない（ウェーブの間は3秒の小休止）。1〜3部屋目は1・2ウェーブ目が取り巻き（2部屋目以降は亡者の冒険者の2人組が混ざることも）、3ウェーブ目に強個体（2〜3特性のエリート）か亡者の冒険者4人パーティ（1人がエリート）。最終部屋は2ウェーブ目に強個体が1体混ざり、3ウェーブ目が10%でボス（4体からランダム）、それ以外は3特性の強個体2体（3人以上なら3体）。ボスの捧げ物で開いた闘技場はボス1体だけ
- **敵は必ず襲ってくる**：部屋の敵は1秒ごとに一番近いプレイヤーを狙い直す（明るい所では大人しいクモも、ダンジョンでは襲ってくる）
- **見た目は毎回変わる**：ダンジョンごとに13種類の石材テーマ（深層岩・古い石レンガ・黒石・海底・砂漠・泥とタフ・ネザー・エンド・氷の宮殿・銅の工房・白亜の神殿・骨の地下墓地・樹脂の回廊）から1つ。部屋ごとに形（四角・八角形・円形・十字）、床の模様（十字・市松・同心の輪・縁取り・斜めの縞）、配置（太い柱4本・円柱の輪・中央の台座・四隅の燭台・列柱・中央のオベリスク・崩れた遺跡・水路・壁沿いのテラス）、飾り（シャンデリア・旗・苔・瓦礫）がランダムに変わる。最終部屋はボスと戦えるよう中央が開けた配置だけ
- **人数補正**：中にいる人数が多いほど敵の体力が増える（1人増えるごとに+40%、ボスはボスの人数補正）。人数が多いと取り巻きも増える
- **報酬**：宝箱の金属はダンジョンのレベルで変わる
  - 各部屋のクリアで小さな宝箱：回復薬・MP回復薬・エメラルド・経験値の瓶（少し）、まれに（5%）スキルの書。金属は銅と鉄（レベルが上がるほど鉄が出やすい）、Lv50から金も。鍵・宝石は出ない
  - 最終部屋の宝箱が一番豪華：回復薬・エメラルド・経験値の瓶・宝石1〜2個、確率で職業書・迷宮の鍵・封印の鍵・ボスの捧げ物（20%）。金属は銅・鉄（Lv50から金）に加えて、**Lv100からダイヤ**、**Lv150からネザライト（欠片・まれにインゴット）とネザライト強化の金型**。ダイヤ以上は最終部屋の宝箱だけ
- **帰り方**：入口ホールの魔法陣（泣く黒曜石）に1.5秒乗ると、いつでも祭壇へ戻れる（逆走で脱出）。最終部屋をクリアすると30秒後に全員祭壇へ強制帰還し、ダンジョンは消えて祭壇は次の捧げ物を待つ
- **死んだとき**：普通にベッド・リスポーン地点で復活。祭壇から入り直せば続きから挑める
- **中のルール**：ブロックの破壊・設置はできない（爆発も地形を壊さない）。ベッド・リスポーンアンカーでリスポーン地点は設定できない。バケツ・火打石も使えない

### 敵同士は争わない

敵（モンスター）の攻撃は、ほかの敵には当たらない（槍を持ったゾンビの突き、スケルトンの流れ矢、ボスの技など）。**クリーパーの爆発だけは周りの敵にも当たる**。敵がほかの敵を狙うことはない（爆発に巻き込まれても仕返ししない）ので、仲間割れは起きない。

### プレイヤーの体力の底上げ

全プレイヤーの最大HPは ×1.3（職業・スキル盤・装備・宝石・熟練ボーナスすべて込みの最終値に掛かる）。Lv199のマス無しで 魔法職 約398／一般的な物理職 約663／盾役 約796。そのぶん敵（レベル持ちのモンスター・ボス・ドラゴン）の攻撃は ×1.15（伸びた体力の半分だけ）強くなる。ボスの「1発で最大HPの20%まで」や環境ダメージ・割合回復は最大HPに比例するので、そのまま同じ割合

### 防御力（RPG式）

バニラの防具計算（大ダメージほど防具が効かず、防御力20で頭打ち）を、RPG向けの計算に置き換えています。

```
防御値 = 防御力×2 ＋ 防具強度×2   （職業・パネル・鍛冶の防御力も含む）
軽減率 = 防御値 ÷ (防御値 ＋ K)     K = プレイヤー80／敵80
```

- 攻撃の大きさに関係なくいつも同じ割合で減り、上限なく効き続けます（100%にはならない）
- バニラの上限（防御力30・防具強度20）は無視して、超えた分も計算に入ります
- **防具のランク補正（プレイヤーのみ）**：上位の防具ほど防御力が上乗せされます。4部位すべてで 鉄＋13／金＋34／ダイヤ＋44／ネザライト＋66（頭・胴・脚・足に配分、部位ごとに付く。革・チェーン・銅は＋0）。上乗せは防具そのものに付くので、防具の説明欄の防御力は上乗せ込みの本当の値（ネザライトの胸当て 8→28 など）。一式の防御力は 鉄28／金45／ダイヤ64（＋防具強度8）／ネザライト86（＋防具強度12）。敵の装備には付きません
- **レベルで防御力は伸びません**：耐久はレベルで伸びる体力が受け持ち、防御は防具（とパネル・鍛冶・宝石）で決まります
- 一式の目安（プレイヤー・Lv1）：革 約15%／銅 約20%／鉄 約41%／金 約53%／ダイヤ 約64%／ネザライト 約71%。レベルでは変わりません。ステータス画面に「被ダメ軽減」として表示
- 目安：Lv100のゾンビ（素の一撃 約70）に対して、ダイヤ一式のLv100ファイター（体力約260）は約10発耐えます
- 敵の装備は K=80 なので効き目は半分ほど（ダイヤ一式の敵で約41%）。敵の武器の攻撃力は15%だけ加算（武器はプレイヤーと同じ3倍スケールなので、元のスケールで45%分。素材の倍率も45%分：ネザライトなら×1.2）
- **体力に合わせた回復と環境ダメージ**：体力が数百になるので、バニラの量（体力20向け）は「最大体力÷20」倍になります。満腹での自然回復・治癒のポーションなどの回復と、敵のいないダメージ（落下・溶岩・炎・溺れ・空腹・毒・ウィザー・サボテンなど）。奈落と /kill はそのまま。MODの回復（スキル・宝石・回復薬）は今までどおりの量
- **治癒のポーション（即時回復）**：バニラの回復量1につき最大HPの2%（治癒I＝8%、治癒II＝16%。以前は20%／40%）。飲む・スプラッシュ・残留すべて
- **再生の効果**：1回の回復は最大HPの2%（再生Iで毎秒0.8%、再生のポーション1本で36%、延長で72%、金リンゴで8%）。スキル（祝福・大いなる奇跡・練気・守護天使・ルーン）と不死鳥の宝石の再生は以前と同じ1回5%。祝福は効果時間8→14秒で、1回の量を減らして合計の回復量は以前と同じ
- エンチャントの防護と耐性エフェクトはこのあとにバニラどおり掛かります。スキルの魔法も防具で減ります（毒など防具を無視する攻撃は今までどおり）
- 設定：`rpgArmor`（オフでバニラ式）、`playerArmorReductionK`、`monsterArmorK`、`monsterWeaponEffect`

### 敵の装備

エンダーマン・エンダードラゴン・ウィザーなどのボス以外の敵対モブは、レベルに応じてランダムに防具と職業の武器を持って出現します（ドロップはしません）。クリーパーは防具を着ません。クモのように見た目に表示できない敵も、防具の防御力と武器の攻撃力は内部でちゃんと効いています。

- 防具は各部位 25〜65%（Lvが高いほど多い、Lv150で最大）、武器は 50〜85%（Lv130で最大）
- 近接の敵は剣・短剣・メイス・ハンマー・杖のどれか、スケルトンは弓（射撃を続けます）。弓・クロスボウ・トライデントで撃つ敵（ピラジャー、ピグリン、ドラウンドなど）とウィッチの手はそのまま
- 素材：Lv1〜29 銅・鉄／Lv30〜66 鉄・銅・金／Lv67〜104 鉄・ダイヤ・金／Lv105〜134 ダイヤ・鉄／Lv135〜 ネザライト・ダイヤ（ネザライトはLv135以降のみ。装備の段階は敵のレベルの1.5倍かけて上がり、Lv150で以前のLv100相当）
- **防具は見た目に表示しません**：防具は内部で着ていて（防御力はそのまま効く）、見た目は素のゾンビやスケルトンのまま。武器は今までどおり見えます。カボチャ・頭ブロックも見えます。設定 `showMonsterArmor` をオンにすると防具も表示
- 設定 `monsterEquipment` でオフにできます

行動パターンはレベルに関係なく全員が持っています（レベルで変わるのは命中精度・連射速度・掘る速さ・導火線の長さなどの強さだけ）。

### 蘇生MOD（Resurrection）との連携

Resurrection を一緒に入れると、ダウン中のプレイヤーは敵に狙われなくなります（入れていなければ何もしません）。

- 敵はダウン中の人をターゲットに選ばず、すでに狙っていた敵も手を離して他のプレイヤーを探す（ゾンビの壁越し索敵、スケルトン、ピグリンなど全部）
- キングスライムはダウン中の人を狙わず、ダウン中の人の近くには出現しない
- ドラゴンはダウン中の人を攻撃対象に選ばず、羽ばたきや怒りの衝撃波でも吹き飛ばさない（奈落に落とされない）
- 蘇生されたら、また普通に狙われる

### エンダードラゴン（3段階のボス戦）

すべての大技は先に予兆が出ます（地面の紋章、範囲の輪、赤い線、咆哮）。ボスバーに「Lv100・形態」が表示され、色も変わります。

| 形態 | 体力 | 追加される攻撃 |
|---|---|---|
| 第一形態 | 60%以上 | 紋章を出した地点に火の玉を連射（3発） |
| 第二形態 | 60〜25% | 連射4発、止まっている間の翼の突風（範囲の輪→吹き飛ばし）、追尾する虚空の弾（浮遊）、虚空からファントムを召喚 |
| 最終形態 | 25%未満 | 連射6発、赤い線で狙った相手に突進、紋章の位置に空からドラゴンブレスの雨。形態が変わるときは衝撃波 |

ドラゴンの攻撃はブレスも含めて×8（プレイヤーの体力がLv199で500まで伸びるのに合わせた値。ブレスは防具を無視するのでレベルの伸びは使わず固定。設定 `dragonDamageMultiplier`）。

- **体力**：ダンジョンのボスと同じく 2600 ×（レベルによる伸び、サーバーにいる一番高い職業レベルで計算）×（1＋0.6×(サーバーの人数−1)）。Lv130・1人なら約8万7千。観戦者は数えず、人が出入りしたら残りの割合を保って変化（設定 `dragonBaseHealth`、`dragonHealthPerPlayer`）
- **どこに当てても同じダメージ**：バニラでは頭と首以外は4分の1しか入らず、止まり木にいる間は矢が効かなかったが、どの部位でも全部入り、止まっている間も矢が当たる
- **1回に削れる量に上限**：止まり木に降りている1回、または降りてくるまでの1回の飛行（最長30秒）ごとに、削れるのは最大体力の10%まで（最低10周）。降りている間に上限に達すると盾の音とともにすぐ飛び立つ。飛行中に達すると、次に降りるまで攻撃が通らない（画面下に表示）。どんなに火力があっても全部の形態を見ることになる
- 設定：`dragonHealthPerPlayer`（0.6）、`dragonMaxShare`（0.1、0で上限なし）

### 裏ボス：深淵のウィザー

エンダードラゴンを倒すと、近くにいた全員が**深淵の鍵**を手に入れる。ダンジョンの祭壇に捧げると、深淵のウィザーの闘技場へ直行。

- 普通のウィザーの1.6倍の大きさ。体力はエンダードラゴンと同じ式（2600 ×レベルの伸び ×（1＋0.6×(人数−1)））。**レベルはLv200で固定**（1人で体力 約13万8千）
- ダンジョンの中なのでブロックは一切壊れない。普通のウィザーの勝手な頭蓋弾・ブロック破壊・出現時の爆発・後半の矢の無効化はない
- ほかのボスと同じルール（1発で最大HPの20%まで、前半は50%で止まる、2セットに1回の「チャンス」）。チャンスでは**力尽きて床に沈む**（被ダメ1.4倍）
- 普段は獲物の周りを低く旋回する（近接でも殴れる高さ）。技を3つ（後半は4つ）続けて出す

技（すべて予兆つき・回避可能）：
- **頭蓋弾の連射**：3つの頭がそれぞれ近くのプレイヤーへ黒い頭蓋を撃つ（3回、後半4回）。当たると衰弱
- **蒼の頭蓋の雨**：全員の足元と周りに青い魔法陣 → 青い頭蓋が落ちて爆発（衰弱）
- **急降下**：少し上昇し、進路に赤い帯 → 一直線に突っ込む。当たると吹き飛ばされる（後半は2連続）
- **衰弱の波動**：周りの輪が満ちていく → 衰弱の波で吹き飛ばす。張り付いていると優先して使う
- **骸骨召喚**：ウィザースケルトンが床から這い出る（2体＋人数の半分、同時に最大5体）
- **後半（50%以下）**：光の鎧をまとって覚醒（この間は被ダメ0.3倍、周りを吹き飛ばし骸骨を呼ぶ）。**三条の死光線**（3つの頭がそれぞれ別のプレイヤーに照準 → 止まった直後に光線）と**頭蓋の嵐**（4方向に渦を巻いて頭蓋をばらまく）が加わる
- 報酬：スキルの書（ほかのボスと同じ）とネザースター

### ダンジョンのボス（キングスライム／ゴーレム／亡者の王／蜘蛛の女王）

ボスは**ダンジョンにだけ**出ます（ブラッドムーンは廃止）。
- ダンジョンの最終部屋で、3ウェーブ目に40%の確率で4体のどれか
- 祭壇にボスの捧げ物（スライムの王冠・ゴーレムの核・魂の器・女王の繭）をすると、そのボスの闘技場へ直行

ダンジョンの中ではブロックを置くことも壊すこともできない（プレイヤーも敵も）ので、穴や柱、トンネルを使ったハメはできません。

| | |
|---|---|
| レベル | ダンジョンの敵レベル（中にいる一番高い職業レベル、封印の鍵なら固定）。ダンジョンの外（スポーンエッグ）では一番高い職業レベル＋0（`levelBonus`） |
| 体力 | 2600（以前は1400：一般的な職のソロで計算上4〜5分になるよう調整。Lv130で約8万7千）×（敵と同じレベルの伸び）×（1＋0.8×(ダンジョンにいる人数−1)）。人数が変わったら残りの割合を保って変化。バニラの最大体力上限（1024）を超える分は、表示上の体力を1000にして受けるダメージを同じ比率で割る（物理・魔法・矢・毒など全部同じ。ダメージ数字は割る前の値で表示） |
| 半分の壁 | 前半（体力50%より上）は、どんな大ダメージでも体力50%で止まる。後半に入って演出（約2秒）が終わるまでは50%より下がらない。チャンスに大技を重ねても後半を飛ばせない |
| 被ダメ上限 | 1発で最大体力の20%まで（防具の前） |
| 報酬 | 倒したときに攻撃した人・近く（48ブロック）にいた人全員に **スキルの書×3**。右クリックでスキルポイント+1（しゃがみ右クリックでまとめて）。職業を変えてもポイントは残ります |

**水の上の相手（共通）**：ボスは水に入りません（歩くボスは水を避けて進み、水に落ちたら一番近い陸地へ大ジャンプで戻る。亡者の王は瞬間移動）。深い水の上やボートにいるプレイヤーには追って入らず、その人に一番近い岸へ大ジャンプして、遠距離の技（キングスライム：スライム弾・スライムの雨、ゴーレム：岩投げ・落石、蜘蛛の女王：糸吐き・卵、亡者の王：ノヴァ以外）に切り替えます。さらに約4秒ごとに**追尾弾**（3発、後半5発）をボスの頭上から撃ちます。弾は相手を追って曲がるので、横に大きく動くか壁や地形で防ぐ。

**チャンス（共通）**：どのボスも技を3つ（後半は4つ）続けて出し、**2セットに1回**だけ大きな隙（約2.5秒・被ダメ1.4倍、足元に金の輪・ボスバーに「チャンス！」）ができます。技の後の小さな隙は短く、被ダメ増加なし。壁にぶつけたときのダウンは約2.3秒・1.4倍。

**リズム**：素早く跳ねて追いかけ → 技を3つ（後半は4つ）連続で出す → 2セットに1回 **ヘトヘト**（へたり込み、汗）→ また追いかける。分裂の咆哮の後もヘトヘトになります。

技（すべて予兆つき・回避可能）：
- **叩きつけ**：着地点に赤い円 → 大ジャンプ → 円の中にダメージ＋地面を這う衝撃波の輪（ジャンプで避けられる）→ 一瞬の着地硬直
- **連続ホップ**：小さな円つきの低いジャンプを4回（後半6回）連続で追ってくる。着地ごとに小さな波紋
- **突進**：進路に赤い帯 → 一直線に滑ってくる（横へ避ける）。通った跡にベタベタの水たまり（踏むと鈍足）。**壁にぶつけるとダウン**でチャンス
- **スライムの雨**：膨らんで空へ打ち上げ → 各プレイヤーの足元と周りに青い円 → 順番に降ってくる
- **スライム弾**：遅い弾を3発（後半5発）。当たると移動速度低下
- **分裂**：体力75%・50%・25%で一回り小さくなり子スライムを吐き出す（2匹＋人数ぶん）
- **後半（50%以下）**：紫に光って速くなり、3連続の叩きつけ、**地鳴らし**（3回跳ねて足踏み→リズムよく広がる輪を3回ジャンプ）、**吸収**（子スライムを引き寄せて回復。先に倒せば防げる）が加わる
- 体当たりは跳ねて乗ってきたときだけ当たるので、近接職でも横で殴り続けられます

#### ゴーレム

高さ約6ブロックの黒い石の巨人。体のひびと胸の核が赤く光る。レベル・体力の計算（`golemBaseHealth`）・被ダメ上限・報酬はキングスライムと同じ。

**リズム**：ゆっくり歩いて追ってくる（近くにいると殴る）→ 技を3つ（後半は4つ）連続 → 2セットに1回 **オーバーヒート**（ひざをついて核がむき出し、湯気）→ また追いかける。

技（すべて予兆つき・回避可能）：
- **叩きつけ**：両腕を振り上げる → 周りに赤い円 → 円の中にダメージ＋地面を這う衝撃波（ジャンプで避けられる）
- **岩投げ**：地面から岩をはがして頭上に掲げ、狙ったプレイヤーへ投げる。着地点に赤い円、着弾で破片が飛び散る（後半は2個）
- **地割れ**：片足を上げて足踏み → プレイヤーに向かって赤い帯 → 帯に沿って岩のトゲが順に突き出る（横に避ける）
- **突進**：進路に赤い帯 → 一直線に走る。**壁にぶつかるとダウン**
- **薙ぎ払い**：近くに張り付いていると、腕を大きく引いて周りをなぎ払う（大きく吹き飛ばす）。予兆の円を見て離れる
- **落石**：咆哮 → 全員の足元と周りに円 → 空から岩が順に落ちてくる
- **跳躍**：歩いて行けない場所（塔の上など）にいる相手には、着地点に円を出して飛びかかる
- **後半（50%以下）**：核が赤熱して速くなり、叩きつけが**3連続の地震**（広がる輪を3回ジャンプ）に
- **岩の鎧**：体力50%と25%で、周りに光る岩の柱を3本（＋人数分、最大6本）立てる。柱が1本でも残っている間は**被ダメ半分**（体がオレンジの渦に包まれ、柱から光の筋が伸びる）。柱を全部壊すと鎧が砕けて2秒よろめく（被ダメ1.4倍）。柱の体力は 15 ×（敵と同じレベルの体力の伸び）：同じレベルのプレイヤーで3発ほど

#### 亡者の王（リッチ）

高さ約5ブロック、ぼろぼろの紫のローブと金の冠をまとった骸骨の魔術師。亡者の冒険者たちの王。目が青く燃える（後半は紫）。レベル・体力の計算（`lichBaseHealth`）・被ダメ上限・報酬はほかのボスと同じ。

**リズム**：7〜16ブロックの距離を保ちながら浮遊 → 呪文を3つ（後半は4つ）連続 → 2セットに1回 **魔力切れ**（片ひざをつき、杖の光が消える）→ また距離を取る。近づかれすぎると瞬間移動で逃げるので、遠距離職や挟み撃ちが有効。

技（すべて予兆つき・回避可能）：
- **魂の弾**：杖を掲げる → ゆっくりまっすぐ飛ぶ魂の弾を扇状に5発（後半7発）。横に避ける
- **魂の紋章**：全員の足元とその周りに魔法陣 → 少し遅れて魂の柱が噴き出す
- **ノヴァ**：本体の周り（半径7）の地面の輪が満ちていく → 爆発して中の人を吹き飛ばす。輪の外へ
- **死の光線**：細い赤い照準が狙った人を追い、止まった直後に光線が走る。照準が止まったら横へ
- **亡者召喚**：周りに亡者の冒険者がよみがえる（同時に最大4体）。王が倒れると一緒に消える
- **瞬間移動**：囲まれたり追い詰められると煙とともに消え、少し離れた所に現れる
- **後半（50%以下）**：光の嵐の中で立ち上がり（この間は被ダメ0.3倍）、亡者を3体呼び、詠唱が速くなる。**魂の嵐**（渦を巻いて弾をばらまく数秒間）が加わる

#### 蜘蛛の女王

体長約4ブロック、黒と紫の巨大グモ。背中に棘の冠と光る紋様、赤い8つの目。毒は効かない。レベル・体力の計算（`spiderQueenBaseHealth`）・被ダメ上限・報酬はほかのボスと同じ。

**リズム**：獲物を追い回す → 狩りの技を3つ（後半は4つ）連続 → 2セットに1回 **疲れ果てる**（脚を広げて地面に伏せる）→ また追いかける。

技（すべて予兆つき・回避可能）：
- **飛びかかり**：身をかがめる → 着地点に赤い円 → 跳んで円の中にダメージ。届かない場所の相手にも跳んでくる
- **糸吐き**：扇状に粘つく糸を吐く。当たると大きく鈍足
- **毒霧**：体を起こす → 前方に扇形の予兆 → 毒の霧を吹きかけ、しばらく毒溜まりが残る
- **卵**：周りに卵を産み、少しして洞窟グモが孵る（同時に最大8匹）。女王が倒れると一緒に消える
- **疾走**：進路に帯 → 一直線に駆け抜ける（壁にぶつかってもダウンしない）
- **前脚なぎ**：近くに張り付いていると前脚を振り上げて前方をなぎ払う
- **後半（50%以下）**：金切り声とともに卵が一斉に孵り、速くなる。飛びかかりが**3連続**に、**巣の結界**（周りに円 → しばらく蜘蛛の巣が張る）が加わる

#### スポーンエッグ（テストプレイ用）

クリエイティブの「RPG Mod」タブと「スポーンエッグ」タブにあります。ブロックに向かって使うとその場に出現（レベルはほかの敵と同じく近くのプレイヤー基準）。
- **ボス**：キングスライム・ゴーレム・亡者の王・蜘蛛の女王（ダンジョンの外でも戦える）
- **亡者の冒険者**：戦士・魔導士・弓兵・神官・盗賊、と**パーティ**（戦士・魔導士・弓兵か盗賊・神官の4人）。普通に使うと通常の個体（偶然エリートになることはない）、**しゃがんで使うと強個体**（3特性のエリート。パーティは先頭の1人）
- 卵から出た敵は自然に消えない

設定（`rpgmod-mobs.toml` の `[bosses]`）：`kingSlimeBaseHealth`, `golemBaseHealth`, `lichBaseHealth`, `spiderQueenBaseHealth`, `healthPerPlayer`, `levelBonus`, `maxHitShare`, `rewardBooks`

### 設定

`config/rpgmod-mobs.toml`：レベルの決め方（`levelsFromPlayers`, `playerLevelBonusMin/Max`）、移動速度（`monsterSpeedMultiplier`）、ゾンビの索敵範囲（`monsterSenseRange`）、場所方式のレベル範囲・距離、体力と攻撃力の伸び（`healthA/B`, `damageGrowthA/B`）、爆発の伸び、賢いAIのオン/オフ、ブロック破壊のオン/オフ（`breakBlocks`）、ドラゴンの体力・攻撃倍率、3段階ドラゴンのオン/オフ。

## マルチプレイ

- 鍛冶の状態はプレイヤーごとにサーバー側で管理（同時に何人でも可）
- クライアントは入力（どこで止めたか）だけを送信し、温度・加工値・品質・オプションはサーバーで決定
- バーのトークン、時間の妥当性チェック、連打制限で不正・二重実行を防止
- GUIを閉じる・ログアウト・離れると、その時点の出来で完成（加熱前なら素材を返却）

## 数値の調整

`config/rpgmod-synced.toml`（サーバーの値がクライアントにも同期されます） で全ての数値（温度範囲、威力、バー速度、判定幅、品質しきい値など）を変更できます。

バランスはシミュレーションで確認しています：

```
javac -d out $(find src/main/java/com/jo112ss/rpgmod/smithing/core -name '*.java') tools/sim/BalanceSim.java
java -cp out BalanceSim
```

目標値は「実際のルールで仮想的に鍛冶をした結果」から作るので、到達不可能な目標は出ません。剣は約9割の確率で中央が最大・両端が小さめになります。

## ビルド

```
./gradlew build
```

`build/libs/rpgmod-<version>.jar` を `mods` フォルダへ。Java 25 が必要です。

## 武器の追加

`ForgeableWeapons.ALL` に1行追加するだけで、新しい武器（斧など）を鍛冶対象にできます。部位の数と作業量の配分は `TargetProfile`、GUIの画像は `textures/gui/` で指定します。
