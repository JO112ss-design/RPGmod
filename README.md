# RPG Mod

Minecraft **26.3 / NeoForge** 向けのRPG系mod。現在は「鍛冶ミニゲーム」を実装しています。今後、職業と職業ごとの武器を追加予定です。

## 鍛冶ミニゲーム

**鍛冶台**（鉄インゴット×3・鉄ブロック・石レンガ×2・かまど）を右クリックで開きます。

1. **作るものを選ぶ** — 武器6種（剣・短剣・メイス・ハンマー・魔法の杖・弓）と防具4種（ヘルメット・チェストプレート・レギンス・ブーツ）× 銅/鉄/金/ダイヤ。素材は通常クラフトと同じ数
2. **加熱** — 左右に動くバーを止めて初期温度を決める。右ほど高温（威力が高く、バーが遅い）
3. **部位を選ぶ** — 切先・前部・中央・後部・根元をクリック（または 1〜5 キー）
4. **鍛打** — バーを止める（クリック / スペース）。止めた位置で威力が変わる：中央の赤＝強 100% / 黄＝中 75% / 外側の緑＝弱 40% / 枠外＝ミス 0%
   - 叩いた部位に100%、左右の隣に25%
   - 1回叩くごとに温度 −5。温度20以下で強制終了
5. **冷却** — 温度 −15。威力を落として微調整したいときに
6. **仕上げる** — 誤差（不足は×1.0、超過は×1.5で減点）から品質が決まる

| 品質 | オプション数 | 色 |
|---|---|---|
| 普通 | 1 | 灰 |
| 上質 | 2 | 青 |
| 希少 | 3 | 紫 |
| 伝説 | 4 | 金 |

素材が良いほど難しくなります（バーが速く、強・中・弱の幅が狭く、品質判定が厳しい）。難易度：銅×0.85 / 鉄×1.0 / 金×1.1 / ダイヤ×1.2（設定で変更可）。

オプション（重複なし・数値ランダム）
- 武器: 攻撃力、攻撃速度、会心率、会心ダメージ、防御貫通、ボス特効、最大HP、防御力、移動速度、耐久値、獲得経験値、ノックバック耐性
- 防具: 防御力、防具強度、最大HP、移動速度、ノックバック耐性、耐久値、獲得経験値、被ダメージ軽減、ボス耐性（複数部位で重ねがけ可）

- 武器の効果はメインハンドに持っている間、防具の効果は装備している間だけ有効
- 通常クラフトの武器はオプションなし
- ダイヤ → ネザライトへのアップグレードで品質・オプションを引き継ぐ（武器・防具とも）
- 品質・オプション・製作者はアイテムに保存され、受け渡しやサーバー再起動でも消えない

## マルチプレイ

- 鍛冶の状態はプレイヤーごとにサーバー側で管理（同時に何人でも可）
- クライアントは入力（どこで止めたか）だけを送信し、温度・加工値・品質・オプションはサーバーで決定
- バーのトークン、時間の妥当性チェック、連打制限で不正・二重実行を防止
- GUIを閉じる・ログアウト・離れると、その時点の出来で完成（加熱前なら素材を返却）

## 数値の調整

`config/rpgmod-synced.toml`（サーバーの値がクライアントにも同期されます） で全ての数値（温度範囲、威力、バー速度、判定幅、品質しきい値など）を変更できます。

バランスはシミュレーションで確認しています：

```
javac -d out $(find src/main/java/com/jo112ss/rpgmod/smithing/core -name '*.java') tools/sim/BalanceSim.java
java -cp out BalanceSim
```

目標値は「実際のルールで仮想的に鍛冶をした結果」から作るので、到達不可能な目標は出ません。剣は約9割の確率で中央が最大・両端が小さめになります。

## ビルド

```
./gradlew build
```

`build/libs/rpgmod-<version>.jar` を `mods` フォルダへ。Java 25 が必要です。

## 武器の追加

`ForgeableWeapons.ALL` に1行追加するだけで、新しい武器（斧など）を鍛冶対象にできます。部位の数と作業量の配分は `TargetProfile`、GUIの画像は `textures/gui/` で指定します。
